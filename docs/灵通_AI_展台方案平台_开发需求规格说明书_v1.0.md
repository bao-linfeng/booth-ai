## 模块 A · AI智选（智能选方案）

对外产品名「AI智选」，一期核心获客入口。用户描述需求 → 系统从方案库筛选匹配方案并展示效果图。一期是「选」而非「生成」。

### REQ-A-01 参数筛选输入 `[P0]`

- **需求描述：** 提供结构化参数筛选，让客户通过下拉菜单快速表达需求。
- **输入：** 展位尺寸（长×宽×高）、开口方向、适用行业（多选）、设计风格（多选）、预算档位。
- **输出：** 一组结构化的筛选参数对象，供筛选引擎调用。
- **规则规格：** ① 长宽高 / 面积 / 开口均采用下拉菜单选择模式（非自由输入）；② 行业、设计风格多选（选定后选项回显在格内，顿号分隔）；③ 预算档位仅「材料购买预算」一项，页面上显示预算二字即可；④ 展位尺寸按 3×6/6×6/6×9 等标准档位提供下拉。
- **验收标准：** 所有参数均可通过下拉/多选完成，无自由输入必填项；多选回显正确；预算档位仅材料购买预算。
- **依赖：** 方案库元数据（面积/开口/行业/风格/预算档位已打标）。

### REQ-A-02 自然语言输入 `[P0]`

- **需求描述：** 提供自然语言输入框，客户可用一句话描述需求（如「3×6 科技感展台」）。
- **输入：** 一段自然语言文本（可含面积、风格、行业等意图）。
- **输出：** 解析后的结构化需求参数（与 A-01 参数合并）。
- **规则规格：** ① 文本框支持占位提示；② 可与参数下拉同时使用（文字优先覆盖参数）；③ 空参数 + 空文字时点击生成，采用随机抽取方式返回结果（非固定）。
- **验收标准：** 文字输入可被解析；空输入触发随机抽取而非报错。
- **依赖：** REQ-A-03 需求解析。

### REQ-A-03 需求解析（规则 + LLM） `[P0]`

- **需求描述：** 把客户输入（结构化参数 + 自然语言）解析为统一的结构化查询条件。
- **输入：** REQ-A-01 结构化参数 + REQ-A-02 自然语言文本。
- **输出：** 结构化查询对象：面积/长宽高、开口、行业、风格、预算档位、关键词。
- **规则规格：** ① 一期 1.0 用规则解析 + 关键词映射；② 一期 1.5 对接 LLM（通义千问 qwen-plus/banana）解析自然语言；③ 解析结果需可人工干预（客户可在结果页修正参数）。
- **验收标准：** 常见表述（面积/风格/行业/开口）解析准确；LLM 解析失败时降级规则解析。
- **依赖：** LLM API 选型（技术验证项）。

### REQ-A-04 方案筛选引擎（两级判定） `[P0]`

- **需求描述：** 按查询条件从方案库筛选方案，采用「可直接采用 / 相似参考」两级判定。
- **输入：** 结构化查询对象（A-03 输出）。
- **输出：** 匹配方案列表（可直接采用 + 相似参考，各标注原因）。
- **规则规格：** ① 可直接采用：按实际长宽、开口方向、限高、模板适用条件精确匹配；② 相似参考：面积接近但长宽/开口不符时，仅作参考并提示需调整；③ 不显示打分/分数角标（对外不暴露评分）；④ 匹配数量不足时随机补齐至目标展示数。
- **打分规则明细：** 硬性过滤（一票否决，决定「可直接采用」）：① 长宽精确匹配（容差 ≤3%）； ② 开口方向精确匹配；③ 限高满足；④ 模板适用条件满足。 软性打分（仅内部排序，总分 = 各维度加权和，对外不显示分数）：尺寸匹配度 （排序主键，面积偏差 ±5% 内满分，每增 5% 降一档） + 风格匹配（+3） + 行业匹配（+2） + 预算匹配（+2） + 关键词命中（+1/个，上限 +3）。权重为建议值，可配置调整。 判定：硬过滤全通过 → 「可直接采用」按总分降序；硬过滤不通过（长宽/开口不符）但面积偏差 ≤±30% → 「相似参考」并标注差异项。
- **验收标准：** 可直接采用方案精确匹配长宽/开口/限高；相似参考明确标注需调整项；无分数角标。
- **依赖：** 方案库结构化数据（面积/开口/限高/适用条件）。

### REQ-A-05 无匹配处理 `[P0]`

- **需求描述：** 当无任何方案匹配时，不硬给结果，说明原因并引导客户调整。
- **输入：** 筛选结果为空。
- **输出：** 无匹配提示 + 调整引导。
- **规则规格：** ① 说明无匹配的具体原因（如「无 6×9 开口方案」）；② 允许客户修改条件或提交人工处理；③ 不默认放宽要求硬给结果；④ 特殊场景：空参数+空文字时走随机抽取（见 A-02）。
- **验收标准：** 无匹配时给出原因和下一步，不静默返回空或硬给。
- **依赖：** —

### REQ-A-06 结果展示 `[P0]`

- **需求描述：** 展示筛选出的方案效果图，支持查看详情、清单、报馆图素材。
- **输入：** 匹配方案列表（A-04 输出）。
- **输出：** 方案卡片/大图 + 详情弹层。
- **规则规格：** ① 每次展示 3 套方案，每套 3 张效果图；② 点图进详情：3 张效果图 + 方案编码（小字、黑色、居中在图片下方）+ 「查看清单」按钮；③ 不显示方案名称评分/标签；④ 响应式适配（电脑/手机）。
- **验收标准：** 展示 3 套 × 3 张；详情含方案编码与查看清单入口；移动端布局正常。
- **依赖：** 方案库效果图资产、REQ-C 清单。

### REQ-A-07 响应性能 `[P0]`

- **需求描述：** 智能选方案响应速度要求。
- **输入：** —
- **输出：** —
- **规则规格：** ① 智能选方案响应 ≤ 5 秒；② 能快则快，不模拟「AI 生成」节奏（无随机等待动画）；③ 加载态仅显示简单提示。
- **验收标准：** 正常网络下筛选返回 ≤5 秒；无刻意的随机等待。
- **依赖：** 后端筛选引擎性能、缓存策略。

## 模块 B · 品牌/主题调整（图生图）

对候选方案做明确范围内的品牌/主题换肤（行业风格 + 客户品牌色），输出新效果图。公司内部不训练大模型，走外部 API。

### REQ-B-01 换肤输入 `[P0]`

- **需求描述：** 客户选定方案后，输入要替换的品牌/主题信息。
- **输入：** 目标行业风格、品牌色、品牌关键词、可改区域。
- **输出：** 换肤请求参数。
- **规则规格：** ① 行业风格 + 品牌色 + 关键词注入；② 换肤范围明确受限（仅 mask 标注区域可改，结构不可改）。
- **验收标准：** 客户可表达品牌色与风格；换肤范围不越界。
- **依赖：** REQ-B-02 蒙版。

### REQ-B-02 mask 蒙版规范 `[P0]`

- **需求描述：** 为每套方案制作可改区域的蒙版，供图生图使用。
- **输入：** 方案效果图。
- **输出：** 品红蒙版图（与效果图同分辨率）。
- **规则规格：** ① 统一用品红 #FF00FF 标识可改区域；② 避开绿植 / 灵通绿 / 灵通红；③ 与效果图同分辨率、逐像素对齐；④ 首批 PS 手工，后续自动化（材质通道/ Enscape）。
- **验收标准：** 蒙版区域准确、颜色合规、与效果图对齐。
- **依赖：** 设计部制作（当前 21 套待做，为最大缺口）。

### REQ-B-03 图像生成 API（双源） `[P0]`

- **需求描述：** 对接外部图像生成 API 完成换肤。
- **输入：** 原效果图 + mask 蒙版 + 提示词。
- **输出：** 换肤后效果图。
- **规则规格：** ① 双源：通义万相 wanx-x-painting + banana（Nano Banana Pro）；② 通义万相用 mask_color=[[255,0,255]] ；③ 双源需用同一批样本验证，不能只写两个供应商名；④ 本地缓存换肤结果降成本。
- **验收标准：** 双源均可用同一批样本跑通；成本/并发/付费方式已在技术验证中确认。
- **依赖：** S0 技术验证结论。

### REQ-B-04 提示词模板 `[P0]`

- **需求描述：** 预置行业 × 风格提示词模板，支持品牌关键词注入。
- **输入：** 行业、风格、品牌关键词。
- **输出：** 组装后的完整提示词。
- **规则规格：** ① 预置「行业 × 风格」组合模板库；② 品牌关键词按模板变量注入；③ 提示词控制长度（通义万相 ≤75 字）。
- **验收标准：** 各行业×风格组合均有模板；注入品牌词后提示词合规。
- **依赖：** —

### REQ-B-05 输出与前后对比 `[P0]`

- **需求描述：** 展示换肤结果，提供前后对比。
- **输入：** 换肤后效果图。
- **输出：** 1~4 张可选图 + 前后对比视图。
- **规则规格：** ① 输出 1~4 张可选图；② 提供换肤前后对比；③ 客户可选定一张作为该方案最终效果。
- **验收标准：** 可查看前后对比、可选定最终图。
- **依赖：** REQ-B-03。

### REQ-B-06 兜底 `[P0]`

- **需求描述：** API 调用失败时的降级处理。
- **输入：** API 异常/超时。
- **输出：** 原图 + 提示。
- **规则规格：** ① API 失败保留原图；② 提示「稍后重试」；③ 不阻断后续流程。
- **验收标准：** API 失败不影响原方案查看与后续报价。
- **依赖：** —

### REQ-B-07 性能 `[P0]`

- **需求描述：** 图生图响应速度要求。
- **输入：** —
- **输出：** —
- **规则规格：** 单图生成 ≤ 30 秒。
- **验收标准：** 换肤单图 ≤30 秒返回。
- **依赖：** API 并发限制。

## 模块 C · 简化清单导出

客户选定方案后查看/下载简化清单。所有方案（含变体）有唯一编号，无需版本管理。

### REQ-C-01 清单字段（8 列） `[P1]`

- **需求描述：** 简化清单固定 8 列字段。
- **输入：** 方案唯一编号。
- **输出：** 8 列清单数据。
- **规则规格：** 列顺序固定： 序号｜产品名称｜产品型号｜尺寸规格(mm)｜数量｜单价｜总价｜ ERP编码。
- **验收标准：** 列顺序、字段名与规范一致；数据从已核对清单提取。
- **依赖：** 方案库已核对清单数据。

### REQ-C-02 总价公式 `[P1]`

- **需求描述：** 总价自动计算。
- **输入：** 数量 × 单价。
- **输出：** 总价。
- **规则规格：** ① 总价 = 数量 × 单价（单价留空供手填）；② 与 SU 保持一致，三种计算规则：个数、长度、面积。
- **验收标准：** 公式计算正确；三规则与 SU 口径一致。
- **依赖：** SU 端计算规则对齐。

### REQ-C-03 唯一方案编号 `[P1]`

- **需求描述：** 方案编号唯一标识，全平台作为唯一键。
- **输入：** —
- **输出：** —
- **规则规格：** ① 所有方案（含变体）均有按特定规则制定的唯一编号；② 无需版本管理（编号已唯一，变体用独立编号）；③ 编号贯穿模型/清单/图纸/素材/项目记录。
- **验收标准：** 全库编号唯一、无重复；各资产以编号关联。
- **依赖：** REQ-H-04 编号规则。

### REQ-C-05 申请报价按钮 `[P0]`

- **需求描述：** 清单页面提供「申请报价」按钮，由客服提供报价。
- **输入：** 客户点击「申请报价」。
- **输出：** 进入获取报价流程，由客服提供报价。
- **规则规格：** ① 清单页显著位置设「申请报价」按钮；② 点击后进入获取报价流程（模块 F）；③ 携带当前方案唯一编号；④ 报价由客服提供，前端不展示价格。
- **验收标准：** 按钮可见可点；点击携带方案编号进入报价申请，由客服提供报价。
- **依赖：** 模块 F 获取报价。

### REQ-C-06 价格不前端展示 `[P1]`

- **需求描述：** 前端清单不展示价格，价格由客服报价。
- **输入：** —
- **输出：** —
- **规则规格：** ① 前端清单页不展示单价 / 总价 / 预报价等价格数值；② 导出清单文件单价 / 总价留空，供客服填写；③ 客户通过「申请报价」（REQ-C-05）获取价格。
- **验收标准：** 前端无价格展示；导出文件价格列留空。
- **依赖：** REQ-C-05 申请报价。

### REQ-C-07 单位规则 `[P1]`

- **需求描述：** 明确计量/计价单位与换算规则。
- **输入：** —
- **输出：** —
- **规则规格：** 明确计量单位、计价单位、换算规则（如长度按米、面积按㎡）。
- **验收标准：** 单位标注清晰，换算规则明确。
- **依赖：** SU 端规则对齐。

## 模块 D · 报馆图素材（三视图）

选定方案后提供报馆图素材（三视图），辅助施工。注意与 mask 蒙版图、平面素材图区分。

### REQ-D-01 报馆图素材展示 `[P1]`

- **需求描述：** 客户查看方案报馆图素材（三视图）。
- **输入：** 方案唯一编号。
- **输出：** 报馆图素材（三视图）展示。
- **规则规格：** ① 展示三视图；② 标注用途与适用范围（施工/报馆参考）；③ 具体项目报馆施工资料仍需按实际确认。
- **验收标准：** 可查看三视图；用途标注清晰。
- **依赖：** REQ-D-02 报馆图素材资产。

### REQ-D-02 报馆图素材入库 `[P1]`

- **需求描述：** 方案库报馆图素材由灵通制作好入库。
- **输入：** —
- **输出：** 报馆图素材资产。
- **规则规格：** ① 标准方案报馆图素材由灵通制作好入库；② 标准方案未变化时直接调取对应图纸；③ SU 修改结构后重新导出并复核。
- **验收标准：** 入库报馆图素材可用；结构变化后能重新导出复核。
- **依赖：** 设计部制作。

### REQ-D-03 SU 端导出对接 `[P1]`

- **需求描述：** 专业用户进 SU 定制后，由 SU 插件导出特定规则报馆图素材。
- **输入：** SU 修改后的模型。
- **输出：** 特定规则报馆图素材。
- **规则规格：** SU 插件按特定规则导出报馆图素材，AIGC 平台对接读取。
- **验收标准：** SU 导出报馆图素材格式/规则与平台一致。
- **依赖：** SU 端插件能力。

### REQ-D-04 报馆图素材下载 `[P1]`

- **需求描述：** 客户可下载报馆图素材（三视图）高清原图。
- **输入：** 方案唯一编号。
- **输出：** 报馆图素材逐张下载 / 下载全部。
- **规则规格：** ① 素材弹窗内每张图配「下载」按钮，按原文件名下载；② 标题栏「下载全部」 批量下载；③ 无素材时隐藏下载按钮、显示「暂无素材」。
- **验收标准：** 可逐张下载、可批量下载，文件名正确。
- **依赖：** REQ-D-02 报馆图素材资产。

## 模块 E · 平面素材输出

输出方案各墙面平面素材，作为客户平面设计师裁剪/放大/编辑的底图素材，最终导出制作文件。采用 「两个输出口」。

### REQ-E-01 两个输出口 `[P1]`

- **需求描述：** 平面底图输出按「是否经过 AIGC 换主题」分两个出口。
- **输入：** 方案状态（是否换主题 / 是否 SU 改过）。
- **输出：** SU 输出或 AIGC 输出。

- **规则规格：** 观察：① 方案找到速度；② 每套合格方案/每客户项目人工时间；③ 询价转化 （有效询价/报价/采购数量与成本）；④ 不满意归因（尺寸/布局/预算/风格/功能）。先记录试点基线再定目标。
- **验收标准：** 试点期记录基线数据。
- **依赖：** —

## 模块 K · 账户与订阅

统一账户体系，支撑「AI 换主题（图生图）」的登录鉴权与积分扣费。图生图产生费用，付费动作前设 「登录墙」；订阅方案后置，一期先做账户登录与鉴权。

### REQ-K-01 邮箱注册 `[P0]`

- **需求描述：** 客户使用邮箱注册账户。
- **输入：** 邮箱 + 密码。
- **输出：** 账户创建成功。
- **规则规格：** ① 统一邮箱注册；② 邮箱唯一性校验；③ 面向全球客户，注册不依赖手机号。
- **验收标准：** 可邮箱注册；重复邮箱被拦截。
- **依赖：** —

### REQ-K-02 登录方式 `[P0]`

- **需求描述：** 支持「用户名或邮箱 + 密码」登录。
- **输入：** 用户名 / 邮箱 + 密码。
- **输出：** 登录成功 / 失败提示。
- **规则规格：** ① 一个输入框同时支持用户名或邮箱；② 校验失败明确提示；③ 登录成功返回 token。
- **验收标准：** 用户名、邮箱两种方式均可登录。
- **依赖：** REQ-K-01。

### REQ-K-03 登录墙 `[P0]`

- **需求描述：** 免费浏览免登录，付费动作前触发登录。
- **输入：** 客户点击「AI 换主题」。
- **输出：** 未登录则跳转登录页；已登录则进入生成流程。
- **规则规格：** ① 浏览 / 匹配 / 看效果图免登录；② 点「AI 换主题」（图生图付费动作）触发登录墙；③ 登录成功后带方案编号返回并进入图生图；④ 已登录有额度则直接生成。
- **验收标准：** 免费浏览不拦；付费动作前必登录；登录后无缝回跳。
- **依赖：** REQ-K-02。

### REQ-K-04 双入口鉴权 `[P0]`

- **需求描述：** 网页端与 SU 端统一鉴权，SU 端免登录带入。
- **输入：** 网页端：登录凭证；SU 端：插件内账户 token。
- **输出：** 统一身份识别。
- **规则规格：** ① 官网网页端：走到登录墙要求登录；② SU 插件端：插件内默认已登录，点按钮打开网页时token 自动带入（静默登录，无需重复输入）；③ 两端共用同一鉴权接口。
- **验收标准：** 网页端正常登录；SU 端 token 带入后无需重复登录。
- **依赖：** REQ-K-02 / 后端鉴权接口。

### REQ-K-05 统一账户 `[P0]`

- **需求描述：** 网页端与 SU 端共用同一账户与额度。
- **输入：** 账户 + 订阅额度。
- **输出：** 统一账户 / 额度扣减。
- **规则规格：** ① 同一客户无论网页端还是 SU 端，同一账户、同一额度；② 扣费互通，不各记各账；③ 后端统一账户 + 订阅接口。
- **验收标准：** 两端额度互通、扣减一致。
- **依赖：** REQ-K-04。

### REQ-K-06 积分余额 `[P1]`

- **需求描述：** AI 换主题页显示用户头像与积分余额，生成时扣费。
- **输入：** 账户余额。
- **输出：** 头像 + 积分余额显示；扣费后余额更新。
- **规则规格：** ① AI 换主题页右上角显示用户头像 + 积分余额；② 生成时校验并扣除对应积分；③ 余额不足引导充值（订阅方案后置，一期先留接口）。
- **验收标准：** 余额正确显示；生成后余额扣减一致。
- **依赖：** REQ-K-05。
