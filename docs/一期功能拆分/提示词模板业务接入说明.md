# 提示词模板业务接入

## 配置与生效

提示词用途：`filter`（AI 智选需求解析）、`theme`（AI 换主题）、`artwork`（AI 四向图）。

最终请求由固定业务约束、可配置业务正文、真实业务数据构成。自定义正文替换该用途的内置业务正文，固定输出协议、编辑边界及方向约束始终保留。

- AI 智选仅配置全局通用模板。
- 图片业务依次选择：行业＋风格、行业、风格、通用；没有启用模板时使用内置默认。
- 同一用途及适用范围最多一份启用模板；新建默认停用，保存和启用分别操作。
- 已启用模板修改后，新请求使用新修订；任务执行和重试继续使用受理快照。
- 主题缓存包含提示词与模板修订；费用提议和提交间配置变化时沿用 `OFFER_STALE` 流程。

## 输入绑定

| 用途 | 动态输入 | 传递方式 |
| --- | --- | --- |
| AI 智选 | 用户 `text`、实时 `dictionaries`（含展位空间） | 独立 user JSON；system 包含固定协议和业务正文 |
| 换主题 | 行业、风格、品牌色、品牌及补充要求 | 固定注入的需求 JSON；正文可引用对应变量 |
| 换主题图片 | 原始效果图、可用蒙版 | 原有图像接口及资产快照 |
| 四向图 | 所选主题任务的行业、风格、品牌色、关键词 | 固定注入上下文；正文可引用对应变量 |
| 四向图图片与方向 | 已选主题效果图版本、正/背/左/右方向 | 同一参考图独立生成四次，自动注入各方向相机约束 |

图片正文变量：`{{industryLabel}}`、`{{styleLabel}}`、`{{brandColors}}`、`{{brandKeywords}}`。四向图额外支持 `{{directionLabel}}`。

AI 智选不提供正文占位符，避免把不可信用户文字插入系统角色。表单已有值继续由服务端合并，未提及字段保持原值。

变量仅单次替换；用户输入中看起来像占位符的内容保持原文，不递归展开。必需数据独立注入，不依赖模板是否写了占位符。

## 管理 API

接口均要求现有管理员权限，前缀 `/api/v1/admin`。

- `GET /prompt-templates/definitions`：三类用途、内置正文、固定约束、变量来源/示例/空值规则和匹配说明。
- `POST /prompt-templates/preview`：`{ purpose, body, sample? }`；返回校验问题、最终消息或四方向正文、真实执行时的图片附件绑定说明。只渲染，不调用模型、不扣积分。
- 预览 `sample`：`text`、`industryId`、`styleId`、`brandColors`、`brandKeywords`。行业/风格按真实启用字典解析；智选直接读取当前完整筛选字典。未指定图片示例行业/风格时显示“示例行业/示例风格”。
- 列表支持 `purpose`、`enabled`、`industryId`、`styleId`、分页。
- 创建：`{ purpose, body, industryId?, styleId? }`。
- 更新：`{ body?, enabled?, expectedRevision }`。

`variables` 为服务端从正文提取的只读字段。保存/启用时校验用途白名单、未知或不闭合变量、空正文及字典范围。正文最长 30000 字符。模板校验错误提供 `issues`（含字符偏移），并返回 `INVALID_PROMPT_TEMPLATE`；范围错误为 `INVALID_PROMPT_SCOPE`。

## 后台操作

1. 新建时选择业务用途，正文来自服务端内置定义。
2. 图片用途可设置适用行业/风格；“示例行业/风格”仅影响预览，不改变模板适用范围。
3. 修改正文，通过变量按钮引用动态值；切换用途时分别保留未保存草稿。
4. 填写示例数据，点击“校验并生成预览”。四向图可分别查看四个方向。
5. 保存后在列表启用。已有同范围启用模板时需先停用原模板。
