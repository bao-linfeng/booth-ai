## 2. 画面标识与交付口径

1. 建议将经过核验的清单“画面”行作为应交付清单：每个可制作画面有稳定的 `artworkKey`、展示名称、对应清单行 ID 及墙面/位置。名字可以改，稳定键不能靠解析文件名生成。普通材料行不要求有平面素材。
2. 对标准/SU 底图，当前集合中每个 `artworkKey` 恰有一个可交付 PNG；不得有清单外键、重名文件或重复画面。原文件名须与已确认的画面编号/名称规则一致；必须核实物理尺寸、单位、墙面位置和核验依据。清单若目前没有可靠的画面行标识，先用真实清单和 SU 样包制定映射，不能从产品名称猜测。
3. 对 AIGC，四个 `direction` 固定为 `front/back/left/right`，各恰有一张，按方向作为四张独立底图交付，文件名使用方向命名规则。AIGC 结果不要求强行映射为清单画面，也不能用方向名冒充清单画面名；如能建立映射则返回 `artworkKey`，否则返回 `mappingStatus=unresolved` 作为提示，但不阻止四方向原件和整套 ZIP 下载。多画面拆图/跨面拼接不在本期承诺，需另行设计。
4. 清单画面映射由方案核验数据及已确认的 SU 输出规范给出，不由模型在结果里自由填写。标准/SU 素材缺失画面映射、物理尺寸或核验依据时不得发布；AIGC 只能声明视觉方向和生成结果，不能据此推断墙面实际尺寸、开口、清单画面编号或可直接印刷规格。
5. 集合使用技术 `revision` 固定文件成员、文件版本、名称、位置和清单关联；标准/SU 的修订按方案维护。私有四面图用不可变的 `artworkJobId` 固定单次结果，不混用方案库的集合修订。此修订仅用于防覆盖和交付快照，不提供面向用户的版本树。

## 3. 客户端功能

### 3.1 C5-01 查看平面素材

方案详情“平面素材”弹窗显示方案编号、来源（标准/SU/本次换主题）、用途说明和预览。标准/SU 读取 API-014 的方案集合；主题入口带 `themeJobId + resultId + selectionRevision`，服务端核验本人及当前选定结果后只返回该结果对应的任务和素材。未明确选择时按原方案处理，不擅自用账户最新生成结果替换当前方案。

卡片展示画面编号及名称、方向/墙面、原文件名、像素尺寸、物理尺寸（标准/SU 必须已核实，AIGC 可显示“未核实”）、文件大小及预览。主题图还显示对应最终效果和生成任务；不展示为“施工图”或“可直接印刷”。切换方案、账号或最终效果时清除旧数据并忽略过期响应；选择变化后旧任务仅可从其历史任务页按本人权限查看，当前素材入口不得混入旧任务内容。

| 状态 | 展示与操作 |
|---|---|
| 已发布、已复核且有资料 | 显示卡片，按权限提供预览/下载 |
| 标准方案有权但无资料 | `status=absent, items=[]`，显示“暂无素材”，隐藏下载按钮 |
| 主题尚未生成 | 明确提示需发起四面素材任务，不展示原方案底图为新主题产物 |
| 排队/生成中 | 查询本人原任务，展示实际阶段，不显示伪进度百分比 |
| 部分方向成功/映射未解决 | 部分成功时显示缺项与原因；映射未解决但四方向均成功时仍可按方向预览、单张下载和整套下载，并明确标注“方向底图，未完成清单画面映射” |
| 无权、方案下架、存储异常 | 分别提示登录/授权、暂不可用、重试；不以空列表伪装失败 |

### 3.2 C5-02 发起四面正交生成

主题任务终态且本人已选定可用 `resultId` 后，展示本次参考图和费用/授权说明，确认后调用 API-015。输入固定 `schemeCode, themeJobId, resultId, selectionRevision, requestKey`，若有计费提议再带 `offerId`。不允许浏览器传入任意参考图 URL、提示词、种子、模型、墙面尺寸或归属用户；服务端从已选效果、原主题输入及经审核的模板/画面定义构造同一批次上下文。

- 四方向共享同一品牌/风格/参考图、模板快照与一致性参数；模型对 seed 的支持和跨视向效果需真实样例验证，不把“相同种子”当作一致性的证明。四张图的交付语义是方向底图，不承诺已拆分为每个清单画面或已具备准确物理尺寸。
- 请求丢失时同一 `requestKey`、同一请求体重发；刷新后用 `artworkJobId` 查询 API-016。失败或不确定上游调用的重试遵循主题模块的 attempt/幂等约束，不盲目二次生成。
- 生成收费未定（Q09）；未冻结积分费率及权威账本扣费/失败退回能力前，不接受付费任务，不默认为免费。若确认收费，复用 API-092 的受控费用提议扩展 `purpose=artwork` 并在 API-015 校验 `offerId`；如果确认免费，服务端响应明确 `credits.status=not_charged`，不能用前端不展示价格代替决策。
- 后台可查看私有任务用于排障/质量复核，但客户对原素材的访问仍受资料权限限制；四面生成不随主题任务自动触发。

### 3.3 C5-03 / C5-04 下载

逐张通过 API-017，整套通过 API-018，标准/SU 携带集合 `revision`，私有素材携带不可变的 `artworkJobId`；服务端重验方案、任务归属、任务创建时固定的主题选择快照、文件可用性和相应原件下载权限。返回 PNG 原件附件流；ZIP 只打包所选上下文中完整、已标识的原件，保留核验过的原文件名，不混入 mask、三视图或其他主题任务文件。预览走同一受控入口的 `disposition=preview`，单独检查预览授权。

标准/SU 文件名按已核对的画面名称及编号交付；AIGC 文件名按 `front/back/left/right` 方向命名，不以方向名冒充清单画面编号。无素材或生成未完成时禁用正式下载；映射未解决不阻止 AIGC 四方向下载，但必须显示方向底图提示。整包中缺一张则整体失败，不生成缺件成功 ZIP。标准/SU 修订变化提示刷新；私有历史任务按任务创建快照下载，不能静默下载另一次任务。建议 ZIP 名称 `{方案编号}@平面素材.zip`，主题包可加任务短 ID 以避免用户本地同名混淆；最终命名待确认。

## 4. 后台流程

### 4.1 M5-01 标准方案维护

在方案详情资产页复用 API-039～041，`type=artwork`。列出 `artworkKey`、清单行/画面名、墙面/位置、原文件名、像素、已确认的物理尺寸及单位、尺寸核验依据、文件哈希、排序、来源、复核状态。管理员上传/替换 PNG、编辑位置/名称/排序，提供受控后台预览/下载；删除复用 API-096、后台原件取用复用 API-097（增加 artwork 分支，不创建第二套通用文件服务）。

上传先校验实际 PNG 解码、文件与像素限制、单一合法文件名和整套重名，生成不可变文件版本；`artworkKey`、清单画面行、`physicalSize`、单位和 `dimensionEvidence` 均为标准/SU 素材的必填字段，且尺寸核验状态必须为 `verified`，文件名必须遵守经确认的规则。对颜色/透明通道、实际尺寸与像素等印刷相关指标只显示事实和风险，不能仅凭像素宽高声称物理尺寸准确。更换文件、映射、名称、排序、关联模型或清单画面行使集合核验失效，当前发布方案同步下架；重新核对后通过 API-043 `stage=artworks`，API-044 再做整体发布检查。缺少已核实物理尺寸或核验依据时不得通过素材复核、发布或开放标准/SU 原件下载。方案更换纯视觉效果不使标准结构素材失效，但客户主题任务必须使用选定效果的私有集合。

### 4.3 M5-03 私有生成任务

API-049/050 按 `kind=artwork` 查看任务、四方向结果、所选主题效果、模板/模型快照、消耗及失败原因；具有私有素材权限的后台人员才能访问原图，访问记审计。记录人工质量意见，不因后台“查看成功”自动发布公共方案或伪造四方向一致性。生成任务只属于本人；要把生成结果作为公共标准素材必须另走资产授权、画面映射和方案审核流程，本期不增加“一键入库”。

## 5. 服务端状态、一致性和文件安全

| 对象 | 建议状态及生效规则 |
|---|---|
| 方案底图集合 | `absent / pending_review / rejected / verified`；仅已发布方案的 verified 集合对客户交付。标准/SU 的 verified 必须包含已核实物理尺寸、单位、尺寸证据和清单画面映射 |
| 私有生成任务 | `pending / queued / running / settling / succeeded / partially_succeeded / failed`；可用素材只引用验证后的结果，不以任务成功代替完整交付 |
| 四面交付 | `pending / incomplete / ready`；四方向齐全且文件检查通过时 ready。`mappingStatus=resolved/unresolved` 独立记录，未解决不阻止按方向交付，但必须在响应和文件名中明确其为方向底图 |

- 任务创建与 Outbox 同事务；Worker 获取租约，固定选定效果、原方案资产、模板/模型、画面映射与费用快照，外部调用时不持有数据库锁。四方向分别存 attempt 和失败原因，不把一个方向的成功替代另一方向；同任务固定同一上下文。失败、超时不确定、Worker 重启和费用结算沿用主题模块的幂等操作/核对原则。
- SU/标准集合改动锁定方案与素材集合，校验 `expectedArtworkRevision` 并递增；同时使相关审核失效及方案下架。清单画面行或模型变动需在同一事务/锁定顺序下重算素材核验，API-044 重检匹配当前修订的模型、清单、图纸和素材；非画面材料行纠错是否仍需整体下架遵循清单模块，不必凭空重写素材文件。
- 文件先上传临时区并解码、算 SHA-256、限制字节/像素与文件名，成功后用新对象键挂接；业务删除保留项目及任务引用的旧文件。拒绝伪 PNG、重名/路径穿越、异常大图及非本人/跨方案 assetId。模型结果下载只访问已验证提供商域名。
- 图片预览生成受控衍生图，浏览器不拿长期公开存储地址；逐次校验预览/原件权限。文件流返回正确的 `Content-Type`、支持中文的 `Content-Disposition` 和 `Cache-Control: private, no-store`。ZIP 打包固定成员快照并在发流前复核权限和修订，缺件不返回 200；不暴露内部 S3 hostname。
- 建议初始资源阈值（**非业务已定**）：单张 30 MiB/4000 万像素，整套 200 MiB；由 SU 样包、输出模型实测和服务端/网关资源预算冻结。预览缩略图不能替代高清原件，生成结果未达到验证标准时报告不合格，不通过插值扩图假装已满足制作尺寸。

## 6. 逻辑数据模型

以下为建议模型，不代表已建表；复用现有方案资产、任务、审核、存储和 Outbox 机制。

| 实体 | 关键字段/约束 |
|---|---|
| 画面定义 | `schemeId, artworkKey, bomItemId, displayName, wallPosition, expectedDimensions`；键按方案唯一且引用已核验画面项 |
| 标准/SU 集合 | `schemeId UNIQUE, revision, status, modelAssetVersionId, bomRevision, reviewId`；成员快照不可变 |
| 素材资产/文件版本 | `assetId, schemeId, artworkKey?, source=standard/su/aigc, direction?, sortOrder`；`versionId, objectKey, sha256, originalFilename, mediaType, byteSize, width, height, physicalSize?, dimensionUnit?, dimensionEvidence?, dimensionStatus`。`source=standard/su` 时这些尺寸字段必填且 `dimensionStatus=verified`；`source=aigc` 时可为空 |
| 四面任务 | `id, ownerUserId, schemeId, themeJobId, resultId, selectionRevision, requestKey, requestHash, inputSnapshot, status, deliveryStatus, creditOperationIds`；`UNIQUE(ownerUserId, requestKey)` |
| 四面结果 | `jobId, direction, assetVersionId, mappedArtworkKey?, validationStatus`；`UNIQUE(jobId, direction)`，归属与 hash/映射快照固定 |
| 项目引用 | `projectId, schemeCode, themeSelection?, artworkSource, artworkRevision?/artworkJobId?, immutableAssetVersions?, availability`；与报价提交事务一起固定 |

画面定义的生成来源和名称规则要由真实 BOM/SU 数据确认。四面只有 4 个方向的约束不意味着清单只有 4 项；AIGC 的 `mappedArtworkKey` 可以为空，但必须用 direction 文件名和 `mappingStatus` 明确交付语义。已提交项目及审核引用不得被后台替换或对象回收覆盖。

## 7. 接口契约

方案编号按 URL 路径分段编码（例如 `TW66_BK_044_F&B`）；业务 JSON 示例仅作契约说明，响应包装与全局 Schema 统一。身份校验以服务端会话为准，不接受客户端传 userId。401 未登录、403 无权、404 不存在/不可见、409 状态或修订冲突、413 超限、415 非 PNG、422 关联或内容不合规、503 存储/模型不可用；建议用 `error.reason` 细化，现有错误处理尚未支持这些新增原因。

### 7.1 客户端 API-014～018

| API | 完整路由 | 请求与响应 |
|---|---|---|
| API-014 | GET `/api/v1/client/schemes/{code}/artworks` | 可选 `themeJobId, resultId, selectionRevision`，主题上下文三者一起提供；不带则查标准/SU 集合。返回 `source, status, revision? / artworkJobId?, themeSelection?, capabilities, items[]`，每项含 `assetId, artworkKey?, name, originalFilename, direction?, wallPosition?, pixelWidth, pixelHeight`；标准/SU 另必须返回已核实的 `physicalSize, dimensionUnit, dimensionEvidence`，AIGC 可返回空尺寸及 `mappingStatus`。主题未生成返回 `status=not_generated, items=[]`，不回退标准底图。 |
| API-015 | POST `/api/v1/client/artwork-jobs` | `schemeCode, themeJobId, resultId, selectionRevision, requestKey`，计费已启用时还需 `offerId`；新任务返回 202 `{artworkJobId,status,pollAfterMs,credits}`。先按本人和 requestKey 查重：同键同体返回原任务（含选择已变、offer 已过期），异内容 409；只有新请求才检查当前选择，已变化时 409。 |
| API-016 | GET `/api/v1/client/artwork-jobs/{jobId}` | 本人查询：`schemeCode, themeSelection, status, deliveryStatus, directions[{direction,status,assetId?,reason?}], missingDirections, mappingIssues, credits, pollAfterMs`；任务不存在或非本人统一 404；终态失败仍用 200 返回真实状态。 |
| API-017 | GET `/api/v1/client/schemes/{code}/artworks/{assetId}/download` | 标准/SU 必填 `revision`；私有必填 `artworkJobId`，服务端从任务创建时固定的 `themeJobId,resultId,selectionRevision` 快照鉴权，不要求当前选择仍相同；`disposition=attachment/preview`。查成员版本及访问权；附件为 PNG，预览为受控图；任务结果不可用返回 409。 |
| API-018 | GET `/api/v1/client/schemes/{code}/artworks/download` | 标准/SU 必填 `revision`；私有必填 `artworkJobId`，按任务创建快照取得完整四方向结果，不要求当前选择仍相同；完整 ready 集合才返回 `application/zip`，空集合 404，失效/缺件 409，打包失败 503；固定路径须在动态 assetId 路由前正确匹配。 |

建议 API-014 对标准空集合返回 `{source:"standard",status:"absent",revision:0,items:[]}`，SU 变体则为 `source:"su"`；主题 `not_generated` 仍须校验本人当前选择。标准/SU 条目必须返回已核实 `physicalSize, dimensionUnit, dimensionEvidence`；AIGC 条目可返回 `mappingStatus=unresolved` 和空物理尺寸。`capabilities` 仅用于按钮渲染，下载时再次鉴权。AIGC 下载绑定任务创建时的不可变选择快照：后续改选后旧任务仍归本人且可从其历史任务页取用，但“当前结果”的 API-014 不混入旧图。API-017/018 的 `artworkJobId` 必须属于该 scheme/用户，不要求任务结果仍是当前选择，不能用一个合法本人任务的 ID 访问其他方案文件。

### 7.2 后台与相邻接口

| 接口 | 平面素材分支补充 |
|---|---|
| API-039 | `type=artwork` 返回当前集合 `artworkRevision/status`、模型/清单画面绑定、文件版本及预览入口；不返回内部对象键 |
| API-040 | multipart：`type=artwork, file, artworkKey, wallPosition, physicalSize, dimensionUnit, dimensionEvidence, sortOrder, expectedArtworkRevision, requestKey`；standard/su 上传字段必填并验证尺寸状态，上传前验证当前画面定义，返回新修订与 pending_review |
| API-041 | JSON 元数据或 multipart 新文件：`expectedArtworkRevision, requestKey, changeReason`；不得修改所属方案、类型、复核标记；替换写新不可变文件版本 |
| API-096/097 | DELETE 素材成员须带预期修订、原因和幂等键；GET 带 `assetVersionId, disposition` 取授权后台历史原件/预览；两个通用路由新增 artwork 分支，不代表其他类型已实现 |
| API-042/043/044 | readiness 返回缺画面/重名/尺寸或尺寸证据缺失/模型或清单不符/未复核；`stage=artworks` 的核验绑定当前模型、清单画面、已核实尺寸及素材修订；整体发布时重查，不因四面私有任务存在而要求每个用户生成素材 |
| API-049/050 | `kind=artwork` 任务筛选与详情，私有结果需额外权限及读取审计；不通过管理员列表公开客户生成图片 |
| API-092 | 若四面收费，扩展 `purpose=artwork` 的输入及费用提议，绑定选定主题效果和规则快照；计费未冻结前不启用付费 API-015 |
| API-019 | 可选顶层 `artworkJobId` **或** `artworkRevision`：前者须与 `themeSelection: {themeJobId,resultId,selectionRevision}` 同传且归属一致，后者仅用于原方案；两者互斥。提交时固定完整 ready 集合或明确记录 `artworkStatus=missing/pending`，不把四面图当结构清单/图纸；旧修订显式请求 409 |

整包或单张 GET 采用文件流而非 JSON URL；不要把客户端取样 ZIP 与 SU 上传包混用。API-019 的素材可选引用只是报价的设计上下文，缺素材是否允许人工承接沿用报价模块的待补资料政策，不能声称已交付。历史项目按项目授权读取已固定文件版本，**不**用当前方案 API-017/018 取旧件；项目侧素材交付入口、伙伴范围和历史保留期限须在项目接口定稿时补齐。

## 8. 验收矩阵

| 编号 | 场景 | 验收标准 |
|---|---|---|
| A01 | 标准方案与 SU 新结构 | 各返回自身编号下已复核 PNG；物理尺寸、单位和核验依据齐全且已确认；母方案不被新结构覆盖，文件名和画面清单可逐项核对 |
| A02 | 清单映射异常 | 标准/SU 缺画面、重复键/文件名、额外键、位置不符阻止核验与发布；AIGC 映射未解决时按方向底图交付并显示提示；非画面材料行不产生假画面 |
| A03 | 换主题前后 | 未选择/未生成只取对应路径；已选主题不回退老底图；改选不会在当前入口显示旧结果 |
| A04 | 四面完整性和一致性 | 同一输入快照生成前后左右；缺一个方向为 incomplete；完整四方向即允许按方向交付，即使清单画面映射未解决；设计人员比对品牌/风格，模型种子不单独当作验收 |
| A05 | 方向与画面不一一对应 | AIGC 接口保留四方向事实并报告 `mappingStatus=unresolved`；仍可按方向下载，文件名不得冒充清单画面编号 |
| A06 | 单张/整包 | PNG/ZIP 哈希及原文件名正确；中文名有效；缺件、过期修订、存储失败不返回成功空包 |
| A07 | 并发、重复及故障 | 同键同请求一个任务/一次费用；异内容冲突；Worker 重启及不确定上游响应不重复盲发 |
| A08 | 文件与越权 | 假 PNG、超限、跨方案/他人 assetId、过期任务及未授权预览/原件均被拦截，不暴露对象键 |
| A09 | 修改和发布竞态 | 素材/模型/画面映射更改同步失效并下架；旧审核无法放行新文件；旧项目快照不被覆盖 |
| A10 | 计费/项目 | 付费政策未定时不静默免费或扣费；项目固定选定效果与素材状态，缺素材不伪造交付 |

实施验证需以真实 SU PNG、BOM 画面行、品牌效果样本作金标准：自动测试权限、集合修订、ZIP 完整性、文件安全和幂等；设计人员核对物理尺寸、方向、墙面拼接和一致性。本文仅为设计文档，未执行生成/文件交付验收。
