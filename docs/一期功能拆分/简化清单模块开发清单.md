## 1. 范围与交付目标

### 1.1 业务主线

**后台导入源清单 → 预览和校验 → 原子替换 → 条目/单位维护 → 技术核验 → 方案发布 → 客户查看六列 → 授权下载八列空价文件 → 报价申请固定清单快照。**

### 1.2 功能范围

| 范围 | 功能编号/接口 | 本清单交付内容 |
|---|---|---|
| 客户端 | C3-01 | 方案详情内查看已核验清单、单位说明和可用状态 |
| 客户端 | C3-02 | 按当前 `revision` 下载八列空价 XLSX，下载前后鉴权和修订校验 |
| 客户端 | C3-03 | 从清单进入报价表单，携带方案、清单修订和主题选择上下文 |
| 后台 | M3-01 | 源 XLSM/XLSX 上传、固定映射解析、预览、警告确认、原子提交 |
| 后台 | M3-02 | 清单完整条目维护、顺序维护、差异说明、并发冲突处理 |
| 后台 | M3-03 | 个数/长度/面积计量规则维护、服务端精确换算和数量重算 |
| 后台 | M3-04 | 源提取、模型逐项、配套项、单位一致性四项核验 |
| 后台 | M3-05 | 生成与客户端一致的客户版八列空价 XLSX |
| 服务端 | API-009/010 | 客户端查看和下载接口 |
| 服务端 | API-019 | 报价交接增加清单修订和不可变快照 |
| 服务端 | API-051～057 | 后台导入、查看、编辑、规则、核验和导出接口 |
| 基础能力 | 数据、存储、权限、审计 | 迁移、对象存储、权限矩阵、并发幂等、缓存和历史引用 |

### 1.3 明确不包含

- AI 生成材料数量、从效果图反推材料数量、自动报价、支付和积分扣费。
- 客户端编辑材料条目、单位规则或价格。
- 直接把源 XLSM 作为客户下载文件。
- 面向用户的方案版本树；只实现清单技术 `revision`、审计记录和项目快照。
- 通用拖拽 ETL；首期只支持评审确认的真实样表映射。
- 通过前端隐藏列保障价格或源文件保密；所有字段白名单和文件内容控制在服务端完成。

### 3.1 当前实现必须重点复核的差距

- [ ] **G01 源表映射**：当前解析逻辑偏向固定“简化清单”客户模板；需按真实样例实现服务端固定映射，不把客户导出模板等同于任意源 XLSM/XLSX。
- [ ] **G02 XLSM 安全策略**：不执行宏、外链或嵌入对象；确认是否允许带 `vbaProject.bin` 的 XLSM 作为惰性源文件读取，不能因库行为误执行或把安全拒绝误报为业务格式支持。
- [ ] **G03 公式缓存**：业务列遇公式时按冻结口径读取缓存值并标记来源；缓存缺失、错误或不可信时阻断提交，不把重新计算责任转移给服务端静默猜测。
- [ ] **G04 解析字段**：源行号、源工作表、源数量、源单位、提取值、差异说明、价格忽略提示必须可追溯。
- [ ] **G05 客户接口**：响应不能复用后台 DTO；不得出现源资产地址、内部备注、成本、单价、总价或后台人员信息。
- [ ] **G06 导出文本**：产品名称、型号、规格、ERP 必须按文本单元格写入；验证前导零、长编码以及 `= / + / - / @` 前缀不会执行或丢失。
- [ ] **G07 revision 竞态**：导入提交、条目编辑、规则编辑、核验、下载和报价快照统一按同一清单修订语义实现。
- [ ] **G08 模型绑定**：模型替换或绑定版本变化必须使核验失效并下架；核验记录绑定具体模型资产版本和哈希。

## 4. 领域状态、修订与权限

### 4.1 清单状态机

| 状态 | 进入条件 | 客户查看 | 客户下载 | 允许发布 |
|---|---|---:|---:|---:|
| `absent` | 方案尚无清单 | 否 | 否 | 否 |
| `pending_verification` | 首次导入或内容/规则/模型变化 | 否 | 否 | 否 |
| `rejected` | 最近一次核验不通过 | 否 | 否 | 否 |
| `verified` | 当前内容、规则、模型绑定已核验 | 需方案发布及资料授权 | 需方案发布及资料授权 | 仅作为整体发布条件之一 |

预览状态独立为 `ready / invalid / committed / expired`，不得和正式清单状态混用。

### 4.2 修订规则

- [ ] 首次创建清单使用 `expectedRevision: 0`；已存在清单必须严格匹配当前 revision。
- [ ] 条目、单位规则、模型绑定、核验状态等影响清单有效性的操作按确定锁顺序执行。
- [ ] 内容变化在同一事务中完成：保存新数据、递增 revision、清除旧核验、下架已发布方案、写审计记录。
- [ ] 核验也递增 revision；核验记录绑定被审核的内容 revision、内容哈希、规则哈希、模型资产版本和模型哈希。
- [ ] 下载生成固定不可变快照；生成后再次检查 revision、状态和权限，冲突不返回文件。
- [ ] 报价提交在同一事务中读取有效清单并保存不可变条目/单位快照；历史项目不跟随当前清单更新。

### 4.3 权限矩阵

| 能力 | 客户匿名 | 客户登录 | 后台清单查看 | 后台导入/编辑 | 后台核验 | 方案发布 |
|---|---:|---:|---:|---:|---:|---:|
| 查看客户清单 | 按 Q07 | 按 Q07 | - | - | - | - |
| 下载客户空价文件 | 按 Q07 | 按 Q07 | - | - | - | - |
| 查看源文件/源行 | 否 | 否 | 独立授权 | 独立授权 | 按需 | 否 |
| 编辑条目/规则 | 否 | 否 | 否 | `scheme.edit` | 否 | 否 |
| 导入/提交替换 | 否 | 否 | 否 | `scheme.import` | 否 | 否 |
| 提交核验 | 否 | 否 | 否 | 否 | `scheme.review` | 否 |
| 发布方案 | 否 | 否 | 否 | 否 | 否 | `scheme.publish` |

- [ ] 服务端按当前管理员、角色、数据范围和动作权限独立校验；前端隐藏按钮不算权限控制。
- [ ] 查看清单、下载客户文件、读取源文件、编辑、核验、发布分别记录审计事件。
- [ ] 对象存储内部地址、预签名地址和源文件内容不进入无权 DTO、错误、日志或缓存。

| C3-F05 | 六列表格 | 展示序号、产品名称、产品型号、尺寸规格(mm)、数量、ERP 编码 | 保留原顺序，不按 ERP 或型号合并；数量旁显示计价单位 |
| C3-F06 | 单位说明 | 根据 `unitRules` 展示源单位、计价单位、换算说明 | 长度/面积不在浏览器重新计算；说明与服务端一致 |
| C3-F07 | 方案编号 | 页头、说明入口或上下文显示真实方案编号 | `TW66_BK_044_F&B` 等含特殊字符编号显示和请求均正确 |
| C3-F08 | 加载状态 | 骨架屏、加载中禁用下载、切换方案清空旧数据 | 旧请求响应不能覆盖新方案 |

| C3-F11 | 权限回跳 | 需要登录时跳转登录并恢复原方案和清单入口 | 登录成功回到相同方案，不丢失主题报价上下文 |

| C3-F14 | 二进制保存 | 检查 HTTP 状态和 `Content-Type` 后保存 Blob | JSON 错误不能保存为 `.xlsx` |
| C3-F15 | 文件名处理 | 使用 `Content-Disposition` 的 UTF-8 文件名 | 文件名非法字符只安全替换下载名，不改变正文方案编号 |
| C3-F16 | 下载冲突 | 下载前后 revision/状态变化时提示刷新 | 不下载旧修订，也不展示成功提示 |
| C3-F17 | 申请报价入口 | 跳转报价表单，携带 `schemeCode`、`bomRevision` | 不在按钮点击时创建项目 |
| C3-F18 | 主题上下文 | 有本人主题任务时携带 `themeJobId/resultId/selectionRevision` | 服务端重新校验归属；前端不上传材料行或核验状态 |
| C3-F19 | 待补清单报价 | 无清单但方案允许人工承接时允许进入报价 | 不把空清单伪装为已核验快照 |
| C3-F20 | 可访问性 | 表格标题、焦点顺序、键盘操作、错误提示和移动端滚动 | 不只用颜色表达核验/权限状态 |
| C3-F21 | 端到端联调 | API-009/010/019 接真实服务端 | 覆盖成功、空清单、失效、权限、冲突、下载失败和快速切换 |

| M3-F13 | 冲突比较 | 传 `expectedRevision`，冲突时保留本地修改供比较 | 不自动覆盖他人修改；刷新前不丢失本地草稿 |

| M3-F15 | 计量规则面板 | 展示规则集合、引用条目、源单位、计价单位、换算描述 | 不接受任意公式脚本；引用规则不可删除 |
| M3-F16 | 数量预览 | 规则保存前预览受影响条目数量变化 | 服务端重新计算并返回，不信任前端计算结果 |
| M3-F17 | 核验面板 | 固定当前 revision、内容哈希、规则哈希、模型资产 ID/哈希 | 操作开始后内容变化必须提示刷新 |
| M3-F18 | 四项核验 | 提取一致性、模型逐项、配套项、单位一致性独立勾选 | 四项均通过且无阻断错误才允许 pass |
| M3-F19 | 驳回处理 | `reject` 必填意见，显示待解决问题 | 驳回后客户不可查看/下载；已发布方案下架 |
| M3-F20 | 模型选择 | 选择当前方案有效模型资产/版本 | 不允许跨方案模型；服务端取得版本和哈希 |
| M3-F21 | 核验提交 | 使用 `requestKey`，提交成功展示 verificationId 和新 revision | 同键同内容返回原结果；同键异内容提示幂等冲突 |
| M3-F22 | 客户版导出 | 已核验时显示“导出客户清单” | 未核验只允许后台结构化预览，不生成正式客户文件 |
| M3-F23 | 导出预览提示 | 展示八列顺序、空价、公式、说明页内容和不含内部价格提示 | 明确该文件不是源表和人工报价单 |
| M3-F24 | 发布联动 | 清单变更后展示“需重新核验并发布”状态 | 不在清单页直接伪造方案发布成功；复用 API-044 |
| M3-F25 | 审计记录 | 展示清单变更、导入、核验、下载等操作摘要 | 只能查看授权范围；不展示完整源价格或凭据 |

### 6.2 后台表格与交互约束

- [ ] 产品条目不按产品名称、ERP 或规格字符串静默合并；同型号不同规格/位置/计量规则保留多行。
- [ ] 序号按提交顺序由服务端生成连续正整数，前端排序只作为编辑态，不直接提交 ordinal。
- [ ] 数量为十进制字符串；个数建议整数，长度/面积允许小数；最终限制以 F01 冻结结果为准。
- [ ] 不在清单页面录入销售价格；人工报价在 M6 维护，二者 DTO、权限和导出文件分离。
- [ ] 预览、编辑、核验和导出都显示当前 revision，避免操作员误以为正在处理历史版本。

| ID | 任务 | 具体要求 |

| XLS-05 | 公式处理 | 只读缓存值或阻断；不执行源公式，不接受没有可信缓存的业务字段 |
| XLS-06 | 文本读取 | ERP、型号、规格读取为文本，保留前导零和长编码 |

| XLS-08 | 价格隔离 | 读取价格只用于识别/忽略提示，不进入条目、DTO、日志和客户文件 |
| XLS-09 | 行数限制 | 有效行、总行、单元格和空行规则与 F07 一致 |
| XLS-10 | 临时对象 | 解析在事务外；对象上传成功和预览记录失败时清理孤儿对象 |

### 8.5 客户文件生成

固定生成新工作簿：

**工作表“简化清单”**

```text
A 序号 | B 产品名称 | C 产品型号 | D 尺寸规格(mm) | E 数量 | F 单价 | G 总价 | H ERP编码
```

- [ ] A/E 为数值或可接受的精确数值展示，B/C/D/H 强制文本。
- [ ] F 列为空；G 列按 F03 决议生成条件公式或纯空白。
- [ ] `0` 价格与空价格区分；填 0 时总价为 0，空价时显示空。
- [ ] 不增加混合单位总计，不自动生成预报价总额。
- [ ] 设置打开后重算；验证 Excel 和 WPS 打开时空价不被缓存成 0。
- [ ] 新文件不包含宏、隐藏源表、外链、源批注、嵌入对象、成本和内部价格。

**工作表“说明”**

- [ ] 真实方案编号、清单 revision、核验时间。
- [ ] 按条目序号列出源单位、计价单位、换算说明。
- [ ] 说明价格由客服提供、清单适用范围和结构清单边界。
- [ ] 不写后台个人信息、内部审核备注、源文件地址或内部价格。
