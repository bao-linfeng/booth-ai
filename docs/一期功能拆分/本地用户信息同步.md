# 本地用户信息同步详细设计

**版本：** v1.0  
**适用范围：** 参展商公众端（`apps/client`）及 SketchUp 插件端（SU）用户  
**关联接口：** `API-026`、`API-028`、`API-087`、`API-089`、`API-029`、`API-030`

---

## 1. 设计背景与定位

灵通 AI 展台方案平台**不自建独立的用户注册与密码体系**，认证完全对接灵通企业统一 SSO 账户系统。

本地维护一张 `users` 同步表，用于：
1. 记录外部统一账户在本地平台的映射（`external_user_id`）。
2. 保存用户在平台的业务资料（昵称、头像、手机号、公司名称等白名单字段）。
3. 维护本地积分账户、生成任务、历史方案及本人项目报价的归属。
4. 记录用户来源（Web 客户端 / SU 插件端）与类型标识。

---

## 2. 数据库设计（`users` 表）

```sql
CREATE TABLE IF NOT EXISTS users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    external_user_id VARCHAR(128) NOT NULL UNIQUE, -- 灵通统一 SSO 用户 ID
    username VARCHAR(128) NOT NULL,                -- 统一账号用户名 / 手机号
    nickname VARCHAR(128),                         -- 显示昵称
    avatar_url VARCHAR(512),                       -- 头像地址
    mobile VARCHAR(32),                            -- 联系电话
    email VARCHAR(128),                            -- 电子邮箱
    company_name VARCHAR(256),                     -- 企业名称
    user_type VARCHAR(32) DEFAULT 'client',        -- 身份类型: client(参展商), partner(搭建商/经销商), designer(设计师)
    status VARCHAR(32) NOT NULL DEFAULT 'active',  -- 状态: active(正常), disabled(封禁)
    last_login_at TIMESTAMPTZ,                     -- 最近一次登录同步时间
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_users_external_id ON users(external_user_id);
CREATE INDEX IF NOT EXISTS idx_users_username ON users(username);
CREATE INDEX IF NOT EXISTS idx_users_status ON users(status);
```

## 3. 同步业务流程

### 3.1 客户端登录与同步流程（`API-087`）

```
[浏览器客户端]
  │
  ├─ 1. 用户输入统一账户凭据提交至灵通登录接口 (API-026: POST /api/auth/login?site=client)
  │     └─ 外部认证成功，返回外部 JWT 与外部用户标识 (data.data.id, data.data.username)
  │
  ├─ 2. 调用平台本地同步接口 (API-087: POST /api/v1/client/auth/sync)
  │     └─ 携带外部登录凭据与身份标识
  ▼
[平台服务端 apps/server]
  │
  ├─ 3. 验证外部身份真实性（校验 JWT 或通过 API-028 获取详情并核对 ID）
  │
  ├─ 4. 原子 upsert 本地 `users` 记录：
  │     - 若不存在：新建用户记录，写入基础资料与默认积分。
  │     - 若已存在：更新最新昵称、联系方式、头像，并更新 `last_login_at`。
  │     - 若外部标记已被禁用/停用：同步更新 `status = 'disabled'` 并拒绝建立平台会话。
  │
  ├─ 5. 颁发本地平台 Session / JWT，建立平台会话上下文。
  │
  └─ 6. 返回本地 `userId`、白名单个人信息与平台授权状态。
```

### 3.2 SU 插件端静默同步流程（`API-089`）

1. 用户在 SketchUp 插件中已登录，点击进入平台时，URL 携带已签发的统一认证 token。
2. 网页前端提取 token，调用 `POST /api/v1/su/auth/sync`（`API-089`）。
3. 服务端验证 token 合法性，取得外部用户信息并原子 upsert 到同一张 `users` 表中。
4. 保证同一用户在 Web 端与 SU 插件端使用同一条 `users` 记录，共享积分账本和任务历史。

---

## 4. 安全与隔离约束

1. **凭据安全：** 严禁在 `users` 表或日志中持久化明文密码、密码散列或外部原始 JWT。
2. **端点隔离：** `users` 仅用于客户端和 SU 插件端，不能凭 `users` 记录登录后台或获得管理权限。
3. **白名单字段：** 仅提取业务必需字段（ID、用户名、昵称、手机、公司），过滤外部详情中的无关或敏感对象。
4. **状态联动：** 外部账号停用时，本地同步拦截并拒绝签发平台会话；本地标记 `disabled` 时所有业务接口直接拦截（403）。
