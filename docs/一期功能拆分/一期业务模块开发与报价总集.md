# 灵通 AI 展台方案平台｜一期业务模块开发与报价总集

**版本：** v0.1（范围与估算评审稿）  
**日期：** 2026-09-24  
**用途：** 范围确认、模块发包、分端排期、工期评估、报价及逐模块验收。  
**状态：** 根据需求与详细设计整理的待开发工作分解，不是现有代码完成度报告或已确认合同报价。

## 1. 使用口径与依据

### 1.1 阅读结论

一期拆为 **14 个业务/公共能力模块（W01～W14）+ 2 个项目公共工作包（W00、W16）**。客户端仍保留原有七大业务分组，但开发和报价按数据所有权与交付责任重新拆分。

- 每个模块包含所需的客户端 UI、客户端接口联调、后台 UI、后台接口联调、服务端和验收任务。
- **合作伙伴网页归客户端，内部运营/审核/销售页面归管理后台；SU 资产文件由人工导入后台。**
- 一个接口只有一个主责模块；共享路由的业务分支由对应模块实现，公共入口不能重复计价。
- 可以按模块分别开发，但发布、资料核验、身份权限和项目快照存在明确依赖，不能把“独立模块”理解为互不依赖的系统。
- 当前接口总表基线：**客户端 28 + 管理后台 54 + SU 3 = 85 个拟开发接口，另复用 3 个企业账户接口**。新增缺口尚未纳入这一数量。
- 人工报价与联系跟进构成一期成交闭环；成交记录不等于平台支付或下单。

## 2. 一期业务闭环

### 2.1 资产供给闭环

```text
历史方案/标准方案/经授权的 SU 新结构
  → 独立方案编号、母版关系、结构参数与标签（W03）
  → 模型/效果图（W03）+ 蒙版（W07）
  → 已核验清单（W08）+ 报馆图（W09）+ 标准平面素材（W10）
  → 分项核验 → 六类资产检查 → 整体审核发布（W03）
  → 客户可检索/授权取用（W04、W08～W10）
  → 资料纠错、核验失效、下架、重新审核发布
```

**完成标准：** 后台能维护真实完整资产；缺件或未审核不能发布；资料更新不覆盖历史项目文件。设计人员制作和模型逐项核对属于真实人工工作，不用“上传成功”代替。

### 2.2 客户选型到成交闭环

```text
匿名描述需求 → AI 解析与条件修正 → 精确/参考方案 → 详情（W04）
  ├─ 使用原方案 → 授权查看清单/图纸/标准底图（W08～W10）
  ├─ 登录（W01）→ 积分确认（W05）→ 换主题、选最终效果（W07）
  │                                      └→ 按需生成四面素材（W11）
  └─ 无匹配 → 人工需求（允许无方案）（W12）
        ↓
报价申请/人工需求 → 固定资料、需求、来源和归属 → 明确承接人（W12）
  → 销售或伙伴联系、人工补关联方案 → 人工填价与导出（W13）
  → 客服/约定渠道发送报价（W14）→ 记录报价依据和跟进（W12）
  → 成交 / 未成交 / 关闭，并记录结果或原因（W12）
```

**完成标准：** 客户有受理回执，后台有项目，责任人可看到并跟进，报价有固定修订，结果有记录；客服或通知故障不丢已受理项目。

### 2.3 合作伙伴与 SU 闭环

```text
伙伴授权与客户渠道归属（W02）
  → 伙伴只看到自己的项目/授权资料（W12）
  → 下载 SKP（W04）→ SU 修改结构
  → 人工导出新模型/清单/图纸/素材文件
  → 在管理后台手动导入各类资产（W08～W10）
  → 后台分项核验（W08～W10）→ 整体审核发布（W03）→ 项目继续跟进（W12）

SU 已有身份 → URL 携带统一 token → 网页验证 token 换取用户信息 → 建立本地会话（W01）
  → 网页/SU 共用积分（W05）→ 网页业务沿用客户端接口
```

**边界：** SU 结构修改、导出文件由 SU 人工完成，平台不自动接收导出包；资产导入复核走现有后台流程。项目已有方案的更换机制尚未冻结，不能用“补关联”接口覆盖已有方案来声称完成该场景。

## 4. 各模块分端任务、边界与验收

以下每个模块均可拆成 `Wxx-CU`（客户端 UI）、`Wxx-CI`（客户端联调）、`Wxx-AU`（后台 UI）、`Wxx-AI`（后台联调）、`Wxx-S`（服务端）、`Wxx-V`（验收）。没有对应页面的项明确记为不适用，不另行凑页面。

### W00 公共工程与接口契约

- **客户端 UI/联调：** 响应式布局、导航回退、公共加载/空态/异常态；请求层、身份失效处理、文件流下载与错误识别、请求追踪。
- **后台 UI/联调：** 接入现有后台框架，通用列表/表单/上传组件、权限菜单与路由、分页筛选、并发冲突提示。
- **服务端：** 统一成功/错误 Schema、ID/修订/幂等约定、迁移与种子规范；复用现有数据库、存储、API/Worker、Outbox 和队列基础，完善业务所需配置。
- **边界：** 只做各模块确实使用的公共基础。具体权限策略属 W02、资产生命周期属 W03、业务任务恢复属 W06，不重复实现通用平台。
- **验收：** 两端能调用真实 API 并正确处理 JSON/附件、401/403/409/503；接口契约能支持分端并行开发。

### W01 统一账户与平台会话

- **客户端 UI：** 登录表单、官网注册跳转、回跳提示、退出；SU token登录状态、刷新后的身份恢复。
- **客户端联调：** 企业登录 → 平台同步 → 本地会话；登录墙回原方案、不自动付费；SU URL token 验证与失效处理。
- **后台 UI/联调：** 企业后台登录、验证码按外部真实协议接入、管理员同步、权限上下文读取、退出与失效。
- **服务端：** 企业凭据可信验证；`users/admins` 分表同步；可失效平台会话；SU token 验证、users 表同步。
- **依赖/边界：** 依赖企业验签/验票协议；本地授权调用 W02，积分调用 W05；不建设注册密码库、订阅与充值。
- **验收：** 外部成功而同步失败不能放行；普通用户不能登录后台；网页/SU 同一用户；退出后受限接口拒绝。

### W02 权限、伙伴身份、渠道归属与审计

- **客户端 UI/联调：** 按服务端能力展示伙伴入口、资料/操作权限提示；具体业务按钮嵌入各模块页面。
- **后台 UI：** 已同步账户列表/详情、用户及管理员角色授权、伙伴资格、客户渠道归属、操作审计查询。
- **后台联调：** 分页/范围筛选、角色与字段权限保存、伙伴停用、归属纠错、审计过滤；管理员可选列表来源须补齐。
- **服务端：** 操作权限、对象数据范围、资料查看/下载及字段白名单；归属关系与修订；统一审计写入/查询服务。
- **边界：** 本模块管理“谁有资格、客户属于谁”；W12 管理“本项目由谁承接、进展如何”。登录资料同步不能覆盖平台授权或渠道归属。
- **验收：** 列表、详情、文件、批量下载均校验；伙伴不能跨项目；归属变更独立审计；内部成本和私有资料不因隐藏按钮而泄漏。

### W03 方案库、公共资产与审核发布

- **客户端：** 提供公开方案/资产摘要契约，详情 UI 与调用在 W04 实现。
- **后台 UI：** 方案列表、基础/结构/打标/关联编辑、JSON/XLSX 导入预览、字典、模型和三张效果图、六类完整性与审核面板。
- **后台联调：** 草稿新增/修改、导入确认、上传替换、排序、检查、审核、发布/下架、冲突恢复。
- **服务端：** 唯一编号与母版校验、受控字典、导入事务、公共资产与不可变文件版本、就绪状态、技术修订、历史引用保护、整体发布事务。
- **边界：** 通用上传/预览/打包基础只做一次；蒙版、清单、图纸、素材业务核验分别由 W07～W10 提供。W03 负责汇总及最终发布，不替代分项核验。
- **验收：** 打标“已核验”不能自动发布；六类资产缺一或审核过期拒绝；结构变更使用新编号；下架停止新匹配，历史项目原件保留。

### W04 AI 智选、方案详情与模型取用

- **客户端 UI：** 尺寸/开口方向/偏好表单、自然语言、解析来源与修正、最多三套结果、参考差异、详情三视角、无结果、模型下载及业务入口。
- **客户端联调：** 字典 → 解析 → 匹配 → 详情；旧请求不覆盖新结果；前进后退恢复；特殊编号编码；转人工只交接上下文。
- **后台：** 复用 W03 维护数据，不增加第二套匹配配置后台。
- **服务端：** LLM 结构化解析与规则降级、条件覆盖/澄清、硬条件判定、参考候选及确定性排序、空输入随机、公开 DTO、授权模型下载。
- **边界：** 不生成新结构；不使用不合格方案凑三套；不承担 API-020 项目受理；阈值与预算边界待冻结。
- **验收：** 长宽/开口不符不判直接采用，已知超高不能作为参考；无结果可交人工；LLM 故障可解释降级；按原需求验证 ≤5 秒目标。

### W05 统一积分读取、预占结算与对账

- **客户端 UI/联调：** 可用余额、冻结/结算/释放状态与不足提示；余额组件共享，主题及四面页的费用确认交互由各自模块负责。
- **后台 UI/联调：** 用户积分流水及按任务检索、未完成操作状态；复用任务详情链接。
- **服务端：** 对接唯一权威账本、稳定操作号、原子预占/扣除/释放及查询、未完成操作恢复、网页/SU 并发一致性。
- **边界：** 不额外建立第二套余额；外部账本不支持预占时，需冻结等效原子扣费/退款协议。外部账本功能改造由其提供方单独报价。
- **验收：** 并发不透支、重放不重复扣、失败可释放、结算故障恢复不重生成；流水与余额来源一致。

### W06 生成任务公共服务、模型与模板运营

- **客户端：** 供 W07/W11 复用公共任务状态、轮询约定与安全预览能力；页面由消费者负责。
- **后台 UI/联调：** 行业×风格×用途模板列表/编辑、模型配置、主备路由、任务筛选、尝试记录、费用及私有结果受控查看。
- **服务端：** 供应商适配、任务/Outbox、Worker 租约与恢复、调用意图、上游不确定状态处理、结果下载存储、共用缓存机制、模板/配置快照、运行指标。
- **边界：** W06 实现共用执行框架和适配；W07 负责蒙版主题规则，W11 负责四方向一致性与交付规则；积分实际动作委托 W05。
- **验收：** 重复投递/重启不盲目重调模型；上游受理不明时不直接双源重发；配置变更不改历史任务；主备使用同批样本验证。

### W07 品牌主题调整与蒙版

- **客户端 UI：** 原图选择、行业/风格/品牌色/关键词、1～4 张数量、费用确认、任务状态、前后对比、最终选择、失败保留原图。
- **客户端联调：** 能力/offer → 幂等创建 → 查询 → 保存选择；余额刷新、过期报价处理、结果改选后的下游上下文更新。
- **后台 UI/联调：** 三视角原图/mask 配对、上传替换、原图/蒙版/叠加预览、对齐审核；调用 W03 通用资产与审核路由。
- **服务端：** 主题输入验证、offer、同用户缓存规则、原图/mask 固定快照、蒙版转换/区域外保护、结果选择修订；接 W05/W06。
- **边界：** 一任务一个视角；纯视觉不变更材料/图纸；不自动启动四面任务。LOGO/产品图片上传与网页蒙版绘制尚未纳入确认基线。
- **验收：** 无有效 mask 禁止生成；私有结果隔离；部分交付按确认费率结算；选择保存后才进入下游；实测单图 ≤30 秒目标。

### W08 简化清单导入、核验与导出

- **客户端 UI/联调：** 六列无价表格、单位说明、空价 XLSX 下载、资料失效/权限提示、携带清单修订进入报价。
- **后台 UI/联调：** 源文件导入预览、整批确认、条目修改、单位换算规则、四项核验、客户版导出；冲突保留本地编辑。
- **服务端：** 固定样表映射、XLSM/XLSX 安全提取、十进制换算、原子替换、核验证据、变更下架、八列白名单新建文件、项目清单快照读取能力。
- **边界：** 不执行宏，不推算模型材料；不导出源表隐藏价格；报价价格只在 W13 保存。资料冻结由 W12 项目事务调用本模块校验逻辑。
- **验收：** ERP 前导零不丢、三种数量与 SU 金标准一致；Excel/WPS 空价/零价/填价正确；旧修订下载冲突，历史项目条目不变。

### W09 报馆图素材维护与交付

- **客户端 UI/联调：** 图纸弹窗、用途/范围/视向、图片缩放及 PDF 分页预览、单件和整包下载、空态与修订冲突。
- **后台 UI/联调：** 方案图纸页签的上传、替换、排序、删除、预览/下载、视向检查与人工复核；扩展 W03 通用路由 drawing 分支。
- **服务端：** 图纸集合/快照、视向覆盖、绑定模型及规范、变更失效、受控预览与原件/ZIP 交付，复用公共文件能力。
- **边界：** 不以“有三张图”代替视向完整；不把 mask 或 AI 四面图当报馆图；SU 导出的图纸由后台人工导入复核；不承诺自动报馆审批。
- **验收：** 图纸对应当前模型，缺件不返回成功 ZIP；中文原文件名保真；预览权不等于原件下载权；旧项目图纸固定。

### W10 标准/SU 平面素材及统一素材交付

- **客户端 UI/联调：** 素材弹窗、画面/位置/尺寸/来源、PNG 预览与单张/整套下载；按标准集合或私有任务切换上下文。
- **后台 UI/联调：** 画面稳定编号和清单关联、物理尺寸及依据、PNG 上传替换/删除/排序、复核；扩展 W03 artwork 分支。
- **服务端：** 画面定义、标准/SU 集合与修订、模型/清单关联检查；API-014/017/018 的标准和私有任务两类读取分支、文件/ZIP 交付。
- **边界：** 私有任务的创建/质量规则归 W11，W10 只读取已确定的交付状态。标准/SU 必须有核实尺寸与清单映射；AIGC 不伪装成精确画面或直接印刷文件。
- **验收：** 标准/SU 与画面清单逐项对应；主题入口不回退原底图；切换结果不串图；有历史引用的旧文件不被覆盖。

### W11 AIGC 四面正交素材

- **客户端 UI/联调：** 最终效果摘要、单独确认生成、四方向进度/失败、结果与一致性提示；接 W10 的下载入口。
- **后台 UI/联调：** 在 W06 任务详情增加四方向结果、缺项、映射状态及质量信息，不另建任务管理系统。
- **服务端：** 固定本人选定主题快照、四方向共用品牌/模板/模型上下文、分方向尝试与结果、整套交付状态；收费时接 W05 及 API-092 artwork 分支。
- **边界：** 不随换主题自动发起；不改 SKP/BOM/报馆图；映射未解决的完整四方向可按 D5 建议作为方向底图交付，不冒充清单画面。
- **验收：** 四方向齐全、主题风格一致、真实高清输出；缺方向不能整包成功；改选不改变旧任务；收费决策未定前不默认免费或扣费。

### W12 申请受理、项目承接与伙伴协作

- **客户端 UI：** 报价申请、人工需求、回执、伙伴项目列表/详情/跟进；资料冲突或失败保留表单。
- **客户端联调：** 从各业务入口汇总上下文、登录后恢复、幂等提交、伙伴范围查询、历史图纸取用和授权资料展示。
- **后台 UI/联调：** 项目列表/详情、申请及资料快照、归属/承接、分配、跟进时间线、六状态及终态原因、人工需求补关联方案。
- **服务端：** 同事务创建申请/项目/资料快照/归属/明确承接人/Outbox；显式修订校验、项目并发控制、伙伴隔离、跟进状态机、通知投递。
- **边界：** 项目生命周期唯一所有者；W13 提供人工报价记录，W14 提供客服连接；普通客户一期不新增“我的项目”中心。历史素材文件交付缺口须在本模块定稿。
- **验收：** 无悬空项目；网络重发只建一次；来源归属可信；分配不洗掉渠道关系；客户选择改变不改已提交项目；未成交可记录原因用于试点观察。

### W13 人工报价编辑、留存与导出

- **客户端：** 无新增在线价格页面。销售通过客服/约定渠道交付文件；清单页仍无价格。
- **后台 UI/联调：** 从项目清单复制行、填单价/服务行、币种及税口径、有效期/条款、草稿完整性、历史修订、指定版本下载。
- **服务端：** 精确十进制行金额与合计、空价和零价区分、报价不可变修订、导出白名单；保存时同步推进项目修订。
- **边界：** 人工给价格，系统做算术；不据预算自动估价，不回写原材料清单；保存/下载不自动变“已报价”，发送证据由 W12 跟进记录保存。
- **验收：** 金标准金额逐行一致；不完整报价不能正式导出；文件与页面一致且无内部信息；旧报价不被新草稿覆盖。

### W14 在线客服第三方接入

- **客户端 UI/联调：** 详情/询价回执打开客服、加载/离线/故障提示、语言与项目上下文、实际真人收发及双向翻译验证。
- **后台 UI/联调：** 厂商工作台入口、定位项目，验证客服收到上下文且可回复；是否支持工作台深链由厂商协议决定。
- **服务端：** API-021 身份与项目范围校验、白名单上下文、必要短期凭据；具体 connection Schema 随厂商冻结。
- **边界：** 不自建消息存储和聊天服务器；SDK/坐席/翻译订阅是持续第三方成本；模拟客服不作为正式验收。
- **验收：** 指定境内外网络场景真人收发、项目正确且不串户、翻译满足业务要求；客服不可用不撤销已成功项目。

### W16 试点数据、总联调、上线与交付

- **数据：** 设计部提供 10 套完整试点资产，技术侧导入和核对绑定；不能把打标有编号的记录数当作完整可发布方案数。
- **集成：** 客户选型→资料→报价→承接→报价发送→结果记录；主题→四面→报价；伙伴与 SU 人工导入资产；异常和撤权场景。
- **上线：** 部署配置、迁移、备份恢复演练、监控告警、故障排查与回滚步骤、浏览器/移动端检查、性能记录。
- **交付：** 源码及构建部署说明、接口契约、数据库迁移、权限矩阵、验收证据、三角色操作手册的技术内容与培训。
- **业务观察：** 记录试点匹配耗时、生成成功/费用、询价与成交、未成交原因及人工工时；先用日志/项目记录和试点统计表，不默认新增 BI 看板或工时管理系统。
- **边界：** 每模块验收已计入各模块，W16 只计跨模块验证、生产准备和交付；设计制作、人工结构复核、视频/正式排版另列投入。

### 7.3 可填写的正式报价行

每个工作包按以下结构复制填写，未冻结项注明基线和增量条件：

| 工作包 | 客户 UI 人日 | 客户联调人日 | 后台 UI 人日 | 后台联调人日 | 服务端人日 | 验收人日 | 角色日单价 | 小计 | 负责人/交付批次 |
|---|---:|---:|---:|---:|---:|---:|---|---:|---|
| Wxx 名称 | 待填 | 待填 | 待填 | 待填 | 待填 | 待填 | 按角色填写 | 待算 | 待填 |

**计算：** 模块费用 = 各角色确认人日 × 对应日单价后求和；项目开发费 = W00～W14、W16 模块费用之和。税费、项目管理/视觉设计是否含在日单价中须明确，未包含则独立列项，不能暗中重复加到模块内。

**风险预留：** 可按双方确认比例单列，或包含在最终固定报价中；采用人日区间上限报价时，应说明是否已吸收同类风险，避免上限与全额风险金双重计算。

**日历排期：** 按客户端、后台、服务端、验收各角色的有效产能和依赖排期，取资源瓶颈及关键路径；总人日除以团队人数只能作粗算，不能代替排期。正式报价应同时给出人数、投入比例、外部等待时间和批次验收时间。

### 7.4 必须单列的预算

### 7.5 本期报价范围之外/条件项

明确后置：订阅套餐、充值支付、自动估价/下单、AI 自由改结构、组件自由拼装、向量召回与 LLM 二次排序、微信小程序、网页 CAD/PS 编辑器、直接印刷成品保证、大规模方案生产。

条件项：LOGO/产品图上传、匿名申请完整身份恢复、多语言整站翻译、多币种换汇/税率拆分、PDF 报价、通知渠道扩展、已有项目更换方案、独立 BI/工时系统。业务如要求纳入，应补充对应验收与工时，不能仅凭“品牌资料”“海外客服”等文字默认全量包含。

## 9. 模块交付与总体验收清单

### 9.1 每个模块完成的共同条件

1. 对应 CU/CI/AU/AI/S/V 任务完成或明确不适用；界面不是仅静态演示。
2. 服务端鉴权、DTO、数据库迁移、错误状态、并发/幂等和文件契约满足该模块设计。
3. 客户端、后台均使用真实接口完成本模块闭环；第三方能力有真实联调证据。
4. 关联模块可消费其输出；只返回 ID 而下游不能使用不算交付。
5. 模块测试与类型/构建检查通过，提交对应场景的验收记录；人工结构/图像质量由指定业务角色确认。
6. 代码、接口文档、迁移、配置说明、样例和未决问题清单同步交付。

### 9.2 一期总体验收场景

| 场景 | 必须看见的完整结果 |
|---|---|
| 标准方案成交链 | 发布合格方案→匿名匹配→授权资料→申请→明确承接→人工报价导出→实际发送并记录→成交/未成交 |
| 无匹配链 | 条件保留→无方案人工申请→负责人联系→确认方案→固定资料→继续报价 |
| 品牌链 | 登录回跳→费用确认→生成/结算→选最终效果→申请项目，原结构/清单/图纸不变 |
| 四面链 | 明确发起→四方向一致结果→授权单张/整包→项目绑定正确主题，映射/尺寸事实清楚 |
| 伙伴链 | 可信归属→伙伴只看自身项目→跟进/线下报价依据→终态结果，内部价格及备注隔离 |
