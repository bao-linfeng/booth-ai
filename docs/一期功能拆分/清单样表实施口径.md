# 方案清单样表实施口径

2026-09-28 确认：一份 Excel 关联一个已有方案 code；管理员在清单管理中显式选择方案，上传预览后点击确认导入即可整份提交或替换，无须勾选核对或填写变更原因。文件名不能作为方案归属凭证。数据库 `scheme_boms.scheme_id` 唯一约束保证每方案一份当前清单。

导入工作表首行须包含九个表头「产品名称、型号、规格/mm、数量、计量类型、单价/¥、总价/¥、重量合计/kg、ERP编码」，按表头名称读取，列顺序不限，允许额外列；必需表头缺失或重复则拒绝。每个产品行都必须单独填写计量类型（`count` 个数、`length` 长度、`area` 面积），无需填写源单位：`count` 按件计且数量为正整数，`length` 按 mm 解析并换算为 m，`area` 按 mm² 解析并换算为 m²。`mm → m` 除以 1000，`mm² → m²` 除以 1000000。长度/面积数量可为正小数，须保证换算后精度在六位小数内。保持原始行序，同 ERP 的不同规格不合并；导入后仍须人工核验。关联方案由上传界面的选择确定，Excel 无需填写方案编号，也不会因缺少编号产生提示；若说明页明确给出不同方案编号则拒绝。业务列公式不执行，源数据须提供纯值。

本次映射修订为 4；旧映射生成但尚未提交的导入预览不能提交，需重新上传，以免将另一种列定义的预览作为新样表入库。

清单核验以方案关联的当前产品清单为对象，只选择通过或不通过；不要求逐项勾选，也不绑定 SKP 模型资产。选择不通过时须填写核验意见；通过时无须填写。模型资产变化不单独重置清单核验，清单条目变更仍须重新核验。历史核验记录中已有的模型信息保留作审计资料。

后台记录原始单价、总价和重量，金额按源值保存，不依据数量或规格重新计算；旧清单的新增字段保持空值。尤其遮光布的原始总价不等于件数乘单价，不能把件数当计价面积。更新导入列中的任何字段均使当前核验失效，已发布方案下架。

客户接口只返回非价格数据，展示重量；客户 XLSX 仍为原八列表头，单价、总价两列真正为空，不含价格公式，重量保留。后台下载客户版文件同样不含原始价格。旧设计稿中的「序号占一列」和「数量×单价总价公式」不适用于本样表，以本实施口径为准。
