# 方案清单样表实施口径

2026-09-28 确认：一份 Excel 关联一个已有方案 code；管理员在清单管理中显式选择方案，上传预览后点击确认导入即可整份提交或替换，无须勾选核对或填写变更原因。文件名不能作为方案归属凭证。数据库 `scheme_boms.scheme_id` 唯一约束保证每方案一份当前清单。

2026-10-12 修订：导入以业务方简化清单样表（如 `TW36_BK_025_APP@简化清单.xlsx`）为准。工作表首行须包含「产品名称、产品型号、尺寸规格(mm)、数量、单价、总价、ERP编码」，「序号」列可有可无且不读取；按表头名称读取，列顺序不限，允许额外列，全角括号视同半角；必需表头缺失或重复则拒绝。合并单元格横跨整行或各列为同一文字的分组标题行（如「一、展位主框架及配件清单」「62封盖」）自动跳过。样表不区分计量类型，数量须为正整数，统一按 `count`（件）导入；长度/面积类条目在导入后编辑计量类型，`length` 按 mm 换算为 m，`area` 按 mm² 换算为 m²。单价、总价可为空；总价等价格列允许公式，只读取 Excel 保存的计算结果，不在服务端重新计算，无结果时留空；其他业务列遇公式仍拒绝该行。重量无对应列，导入为空。产品名称为空时用产品型号代替并提示；ERP 编码为空时导入为空并提示；数量为空的行不导入并提示，导入后补充；产品名称与型号均为空、数量非正整数或价格非数字的行报错并阻止提交。保持原始行序，同 ERP 的不同规格不合并；导入后仍须人工核验。关联方案由上传界面的选择确定（方案详情中直接导入时即当前方案），Excel 无需填写方案编号；若说明页明确给出不同方案编号则拒绝。

本次映射修订为 6；旧映射生成但尚未提交的导入预览不能提交，需重新上传，以免将另一种列定义的预览作为新样表入库。

清单核验以方案关联的当前产品清单为对象，只选择通过或不通过；不要求逐项勾选，也不绑定 SKP 模型资产。选择不通过时须填写核验意见；通过时无须填写。模型资产变化不单独重置清单核验，清单条目变更仍须重新核验。历史核验记录中已有的模型信息保留作审计资料。

后台记录原始单价、总价和重量，金额按源值保存，不依据数量或规格重新计算；旧清单的新增字段保持空值。尤其遮光布的原始总价不等于件数乘单价，不能把件数当计价面积。更新导入列中的任何字段均使当前核验失效，已发布方案下架。

客户接口只返回非价格数据，展示重量；客户 XLSX 仍为原八列表头，单价、总价两列真正为空，不含价格公式，重量保留。后台下载客户版文件同样不含原始价格。客户导出文件不含序号列和总价公式，以本实施口径为准。
