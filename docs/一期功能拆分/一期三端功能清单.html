03 / API · DATA · WORKER

服务端

以工作包梳理数据、接口、鉴权、文件、生成任务与项目闭环。

W00～W16
17 个工作包

实现能力

根据《一期业务模块开发与报价总集》服务端职责整理
W00

公共工程与接口契约

统一响应／错误 Schema、ID／修订／幂等约定、数据库迁移与种子；复用数据库、存储、API、Worker、Outbox 和队列。

W01

统一账户与平台会话

可信校验企业身份，users／admins 分表同步，可失效平台会话；SU token 验证与用户同步。

W02

用户类型与端入口

保存 users 用户类型标记，在客户端与 SU 当前用户信息中返回；业务操作仍独立鉴权。

W03

方案库与审核发布

方案唯一编号、母版关系、字典、导入事务、就绪汇总、技术修订与发布／下架事务；零资产草稿可保存。

W04

AI 智选与检索分析

LLM 结构化解析及规则降级、硬条件和参考匹配、排序、空条件随机、详情与授权模型下载；检索流水与聚合统计。

W05

统一积分协调

对接唯一权威账本，稳定操作号，余额读取、原子预占／扣除／释放、未完成操作恢复与网页／SU 并发一致性。

W06

生成任务公共服务

供应商适配、任务与 Outbox、Worker 恢复、结果存储、缓存、模板／模型配置快照及运行指标。

W07

品牌主题调整与蒙版

输入与费用 offer 校验、原图／mask 快照、同用户缓存、蒙版转换和区域外保护、结果选定修订；接积分与生成任务。

W08

简化清单导入与交付

XLSM／XLSX 安全提取、十进制换算、原子替换、核验证据、变更下架、八列空价导出及项目清单快照。

W09

报馆图素材维护与交付

图纸集合与修订快照、视向覆盖、模型与导出规范绑定、变更失效、受控预览以及原件／ZIP 下载。

W10

标准／SU 平面素材交付

画面定义、标准／SU 集合与修订、模型／清单映射核验；标准及私有任务的读取、原件和 ZIP 交付。

W11

AIGC 四面正交素材

固定已选主题快照、共用品牌／模板／模型上下文、分方向尝试与结果、整套交付判定，按计费决策对接积分。

W12

申请受理与项目承接

同事务创建申请／项目／资料快照／归属／承接人及 Outbox；提交人本人只读隔离、后台授权、跟进状态机与通知。

W13

人工报价留存与导出

精确十进制金额、空价与零价区分、不可变报价修订、白名单文件导出及项目修订同步。

W14

第三方在线客服接入

校验身份与项目范围，生成白名单会话上下文及必要短期凭据，对接第三方客服平台。

W15

方案资产独立管理

方案与资产一对多、文件不可变版本、Silo 存储、上传登记／失败重试、跨方案查询、权限与历史引用保护。

W16

试点数据、总联调与上线

导入核对试点方案资产，验证选型→资料→申请→跟进→报价及主题→四面链路；迁移、监控、备份恢复与交付材料。

接口边界：客户端、后台与 SU 使用各自接口入口及权限校验，内部业务服务可复用。现有路由文档将接口清单描述为 85 个拟开发接口、另复用 3 个企业账户接口；后续补充的检索分析接口见相关详设，接口数量不用于折算页面或功能项。
