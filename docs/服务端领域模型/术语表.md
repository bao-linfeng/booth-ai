# 领域术语表

本文统一平台业务讨论、接口和服务端模块中的核心词汇。数据库字段名可能使用英文或历史命名，不改变其既有名称。

## 用户与访问者

**参展商用户**：经灵通外部账号同步到本地 `users` 的已登录客户主体。积分、登录后检索记录、生成任务和登录项目归属于用户。

**管理员**：经灵通外部账号同步到本地 `admins` 的后台操作主体。管理员角色和本地权限控制管理端操作；管理员不是项目客户。

**访客**：未登录浏览器或客服访问身份。智选分析使用独立访客标识，在线客服使用 `cs_visitors`；访客不是 `users`，客服访客合并为用户也不自动改变既有项目客户归属。

**客户**：询价或人工需求中希望平台跟进的联系人或企业，是业务角色，不等同于登录账号。联系方式保存在项目请求快照中。

## 方案与交付资料

**展台方案**：可被检索、审核和发布的方案记录，由稳定方案编号 `code` 识别。草稿、审核状态和发布状态分别表达不同维度。

**方案资产**：附属于方案或由生成任务产出的文件逻辑记录。资产类型包括模型、清单、效果图、蒙版、报馆图和平面素材；文件内容通过不可变资产版本记录。

**资产版本**：资产某次文件内容的不可变记录，包含对象 Key、文件名、MIME、大小和校验信息。项目需要历史文件时固定引用版本，而不是依赖资产当前版本。

**方案基线资产**：`scheme_baseline_assets` 视图筛选出的公共方案源资料。用户生成结果属于私有资产，不作为公共方案基线。

**方案修订**：方案或资料业务内容在相应模块中的版本号。清单、图纸、素材和生成结果各自有独立修订语义，不应假定存在一个覆盖所有资料的全局修订号。

## 智选与生成

**智选尝试**：一次访客或用户需求探索过程，记录在 `selection_attempts`，可包含解析与多次检索。

**解析结果**：自然语言需求经模型、规则或未解析路径得到的结构化条件和澄清信息，记录在 `selection_parses`。

**检索记录**：一次按结构化需求检索方案的结果快照，记录命中状态和结果摘要。检索记录是分析与历史呈现数据，不是方案或项目。

**生成任务**：用户提交的异步主题调整或四面素材生成请求。任务状态、结果、供应商尝试与 Outbox 由生成模块及 Worker 管理。

**主题结果选择**：用户在主题生成任务的可用结果中选择一个结果；选择修订用于并发控制和后续四面素材生成上下文。

**四面素材**：与 front、back、left、right 四个展台方向对应的平面交付结果。四面素材任务可固定引用所选主题结果及选择修订。

## 积分、项目与报价

**积分流水**：不可变的积分增减记录。余额是流水聚合结果，不作为独立余额事实维护。

**积分预留**：生成任务执行期间占用的积分额度；任务完成后结算，失败等场景释放。预留与流水由积分模块拥有，任务表由生成模块拥有。

**项目**：平台承接和跟进的一条业务工作记录。询价申请与人工需求都进入统一项目流程；项目保存提交时的需求、方案及资料快照。

**项目来源**：项目由方案询价（`quote_request`）或人工需求（`manual_request`）创建。当前实现将请求详情放在 `projects.request_snapshot`，不是独立的请求表。

**项目事件**：项目生命周期中发生的状态、分配或其他业务事件记录。事件历史与当前项目状态不同，不能把事件当作当前状态的唯一来源。

**报价修订**：项目报价某一版本的不可变快照。更新报价产生新的修订，不覆盖已保存历史版本。

## 在线客服

**客服会话**：由已登录用户或访客发起，与坐席交互的会话。会话具有排队、进行中、关闭等生命周期，与项目承接流程相互独立。

**客服上下文**：客户从方案或项目等页面进入客服时附带的业务引用及快照。上下文帮助坐席理解来意，不代表项目授权或项目归属。

**内部消息**：仅供坐席查看的会话消息；公开消息可面向客户。消息可有按目标语言生成的译文。
