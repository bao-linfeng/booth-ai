# 服务端全量表设计目录

## 口径

本文依据 `apps/server/migrations/001_*.sql` 至 `080_*.sql` 的累计执行结果，枚举业务 schema 中当前保留的表、视图和历史归档对象，并说明它们在现有业务中的职责。ER 关系图见[数据库 ER 图](数据库ER图.md)。

“当前”指从空库顺序执行全部迁移后的结构，不代表连接了某一运行环境并读取其 `information_schema`。迁移 runner 另建 `schema_migrations`；归档表和旧表在技术上依然存在，但不是活跃业务写模型。Redis session、BullMQ 队列和 S3 对象不是 PostgreSQL 表，不列为关系表。

## 身份、权限与审计

| 表 | 用途与关键字段 | 约束与关系 |
|---|---|---|
| `users` | 外部参展商/SU 账号本地同步副本；`external_user_id`、用户名、启用状态、`user_type`、会话版本等。 | 外部用户 ID 与用户名唯一；软业务账户状态由 `enabled` 表达。被项目、生成、积分、客服和选型记录引用。 |
| `admins` | 管理员外部账号同步副本；保存资料、外部角色快照及会话版本。 | 外部用户 ID 与用户名唯一。由方案审核、项目承接、AI 配置、客服坐席和审计记录引用。角色权限通过外部角色 ID 与本地角色配置协作，不建立角色外键。 |
| `admin_roles` | 本地可编辑角色及权限码集合；`permission_codes`、`revision`。 | `name` 唯一；角色以外部 bigint ID 标识。管理员侧角色同步数据不通过 FK 指向本表。 |
| `admin_audit_logs` | 管理端审计事实；操作者、动作、对象类型/标识和 JSON 详情。 | `admin_id` 外键到 `admins`；按操作者、对象和时间建立查询索引。 |

## 方案目录、资产与资料

| 表 | 用途与关键字段 | 约束与关系 |
|---|---|---|
| `schemes` | 展台方案主记录；方案编号、尺寸、字典选项、发布状态、审核状态和修订号。 | `code` 唯一；`parent_code` 自引用方案编号。产品体系、风格、预算档位等单值字典项有 FK；多选行业/分区/特征 UUID 数组无逐项 FK，但删除字典项有触发器保护。 |
| `scheme_imports` | 方案批量导入预览、错误摘要和提交状态。 | `created_by` 可空 FK 到管理员；预览及汇总存 JSON。 |
| `scheme_assets` | 方案/生成素材的逻辑资产；类型、排序、配对资产、来源、所有者和可见范围。 | `scheme_id` FK 到方案；`related_asset_id` 自引用；`owner_user_id` 可空 FK 到用户。`source/visibility/owner` 检查约束区分公共基线与用户生成私有资产。 |
| `asset_versions` | 文件不可变版本；对象 Key、原文件名、MIME、字节数、校验和及尺寸/页数。 | `asset_id` FK 到资产；对象 Key 全局唯一。项目可固定引用历史版本。 |
| `asset_upload_requests` | 新资产上传幂等回执，防止客户端重试重复建资产。 | `(scheme_id, idempotency_key)` 复合主键；方案和目标资产均有 FK，创建管理员可空。 |
| `scheme_reviews` | 方案资产阶段/整体审核历史；方案修订、决定、核验项与备注。 | `scheme_id` FK；`request_key` 唯一；审核管理员可空 FK。审核记录保留历史。 |
| `scheme_boms` | 每个方案的当前简化清单及修订、状态、源资产和核验信息。 | `scheme_id` 唯一 FK；源资产和模型资产受同方案复合外键约束；模型资产版本引用 `asset_versions`。 |
| `scheme_bom_items` | 当前清单行项目；排序、名称、型号、规格、源数量、换算后数量和计量类型。 | `bom_id` FK；同清单 ordinal 唯一；数量、名称等有检查约束；计量单位由枚举文本表达，不再有 unit rule FK。 |
| `bom_imports` | 清单 Excel 导入预览、映射、错误/警告、基线及提交回执。 | `scheme_id` FK；创建人可空 FK；来源 hash、基线修订、状态和过期时间支持幂等与过期清理。 |
| `bom_verifications` | 清单核验请求及结果历史；内容/结果修订、哈希、模型版本和检查结果。 | `bom_id` FK；`model_asset_version_id`、模型资产、审核管理员为可空 FK；`request_key` 唯一。 |
| `bom_change_logs` | 清单修订变化审计；前后 revision、动作、原因和摘要。 | `bom_id` 与 `admin_id` 为非空 FK；after revision 必须大于 before revision。 |
| `dictionaries` | 可配置字典定义，包括选型、计量和展台尺寸等。 | `code` 唯一；`type` 表示字典用途。 |
| `dictionary_items` | 字典值、默认标签、多语言标签、别名和可选尺寸。 | `dictionary_id` FK；同一字典内 `item_value` 唯一。方案引用的多选 UUID 数组靠业务校验和删除保护触发器维护。 |

## 智选与检索分析

| 表 | 用途与关键字段 | 约束与关系 |
|---|---|---|
| `selection_attempts` | 一次访客/用户选型尝试的身份标识和活动时间。 | `user_id` 可空 FK；访客 ID 是文本，不是客服访客 FK。 |
| `selection_parses` | 一次自然语言解析；输入、表单/最终条件、解析来源、澄清、覆盖字段及版本信息。 | `attempt_id` 非空 FK，删除 attempt 级联；`user_id` 可空 FK。 |
| `selection_searches` | 一次方案匹配的请求条件、命中状态、计数和结果快照。 | `attempt_id` 非空 FK；`parse_id` 和 `user_id` 可空 FK；parse 删除时关联置空。结果快照不是方案外键集合。 |

## 生成、积分与 AI 调用

| 表 | 用途与关键字段 | 约束与关系 |
|---|---|---|
| `theme_jobs` | 用户主题调整任务；方案编码、来源资产、输入快照、任务状态、结果选择及选择修订。 | `user_id` 非空 FK；`search_id` 可空 FK；`cached_from_job_id` 自引用可空 FK。用户+request key 唯一。方案编码和源资产标识由业务校验，不是 FK。 |
| `theme_job_results` | 主题任务生成的逐张结果、排序、预览和资产版本。 | `job_id` FK 级联；ordinal 在任务内唯一；`asset_version_id` 可空 FK。`asset_id` 是文本标识。 |
| `theme_job_outbox` | 主题任务事务性入队 Outbox。 | `job_id` FK 级联且唯一，每任务至多一条 Outbox 记录。 |
| `theme_job_generated_urls` | 主题生成阶段暂存的供应商结果 URL，供结算幂等消费。 | `job_id` FK 级联；ordinal 在任务内唯一。 |
| `theme_job_provider_attempts` | 供应商调用尝试、模型、修订、未知结果及请求追踪信息。 | `job_id` FK 级联；模型 ID 为历史/诊断字段，不设 FK 到当前模型配置。 |
| `artwork_jobs` | 四面素材任务；可按单方向或固定主题结果/选择修订生成，含生成及交付状态。 | `user_id` 非空 FK；主题任务、主题结果为可空 FK 且删除受限；用户+request key 唯一。方案编码/源资产 ID 由业务校验。 |
| `artwork_job_results` | 四面任务逐方向交付结果及不可变资产版本。 | `job_id` FK 级联；方向唯一索引；`asset_version_id` 可空 FK 到 `asset_versions`。 |
| `artwork_job_directions` | 每方向的提交、生成和失败状态，以及供应商追踪信息。 | `(job_id, direction)` 复合主键；job 删除级联；方向受固定集合检查约束。 |
| `artwork_job_outbox` | 四面素材任务事务性入队记录。 | `job_id` FK 级联且唯一。 |
| `credit_transactions` | 积分账本不可变流水，含签到、充值、主题/素材消费、操作管理员及幂等字段。 | `user_id` 非空 FK；主题和素材任务可空 FK 且部分唯一；充值请求键按操作管理员唯一。余额由视图聚合，不单独存余额表。 |
| `credit_reservations` | 生成期间预留、结算或释放的积分。 | `user_id` 非空 FK；主题 job 或 artwork job 恰好一个非空；各自唯一 FK。状态受检查约束。 |
| `sign_in_records` | 用户每日签到防重记录。 | `user_id` FK；`(user_id, sign_date)` 唯一。 |
| `sign_in_config` | 单行签到开关、每日积分和时区配置。 | boolean 主键检查保证单例；积分数值范围受检查约束。 |
| `ai_providers` | AI 供应商协议、Base URL、加密凭据及模型目录缓存。 | Base URL 仅允许 HTTPS；规范化名称唯一；凭据密文和加密上下文保存在数据库。 |
| `ai_models` | 供应商下的文本/图像模型、供应商模型标识和参数。 | `provider_id` 非空 FK 且删除受限；同供应商模型标识唯一。 |
| `ai_model_assignments` | 按业务用途配置模型优先顺序和生成积分单价。 | `(purpose, model_id)` 复合主键；模型 FK；每用途 position 唯一。解析/客服翻译等文本用途不计生成积分。 |
| `prompt_templates` | 主题/素材生成提示词模板；用途、行业/风格匹配、模板正文、变量、启用状态与修订号。 | 行业、风格字典项和创建/更新管理员为可空 FK；同一用途+行业+风格至多一条启用模板的部分唯一索引。 |

`user_credit_balances` 是视图，不是表。任务状态的 enum 类型为 `theme_job_status`、`artwork_job_status`；其定义不增加独立实体表。

## 项目、报价与通知

| 表 | 用途与关键字段 | 约束与关系 |
|---|---|---|
| `projects` | 统一询价/人工需求项目；业务号、来源、客户/访客、承接管理员、状态、revision 和请求/方案/资料快照。 | `project_no`、`request_no` 唯一；用户、客服访客可空 FK；承接管理员非空 FK。请求详情内嵌 JSON，不存在活动 request 子表。 |
| `project_asset_versions` | 项目固定使用的资产版本集合。 | `(project_id, asset_version_id)` 复合主键；两端均为非空 FK 且删除受限。 |
| `project_operations` | 写操作幂等回执；操作者类型/ID、操作、目标、request key、payload hash 和响应。 | 复合主键覆盖 actor、operation、target、request key；多态 `actor_id` 不引用 users/admins FK。 |
| `project_events` | 项目事件/跟进历史；事件类型、操作者、载荷和时间。 | `project_id` 非空 FK；`actor_admin_id` 可空 FK。当前跟进记录作为事件载荷存储，不另设 follow-up 表。 |
| `project_quotation_revisions` | 项目报价不可变版本快照。 | `(project_id, revision)` 复合主键；项目和创建管理员非空 FK；revision 必须为正数。 |
| `project_assignment_config` | 单行项目默认承接管理员及配置修订。 | boolean 单例主键；默认承接人和更新人可空 FK 到管理员。 |
| `project_notification_outbox` | 项目事件对外通知的待发、租约、重试和终态状态。 | `project_id` 非空 FK；`event_id` 非空且唯一 FK；投递状态字段支持租约与有限重试。 |
| `project_notification_reads` | 管理员对项目通知的独立已读状态。 | `(admin_id, notification_id)` 复合主键；两端 FK，删除管理员/通知时级联删除读状态。 |
| `project_receipt_emails` | 项目受理回执邮件投递状态。 | `project_id` 非空唯一 FK；保存收件人、语言、重试租约、错误及投递结果。 |

## 在线客服

| 表 | 用途与关键字段 | 约束与关系 |
|---|---|---|
| `cs_visitors` | 匿名客服访客标识；只存令牌 SHA-256、语言和可选合并用户。 | token hash 唯一且格式检查；合并用户可空 FK；删除采用软删除时间。 |
| `cs_conversations` | 客服会话及客户身份、队列/坐席、语言、未读序号和关闭信息。 | 客户 user 与 visitor 恰好一个非空；状态与坐席/关闭时间有一致性检查；每个主体至多一条未关闭会话的部分唯一索引。 |
| `cs_conversation_contexts` | 会话关联的方案/项目上下文快照。 | `conversation_id` 非空 FK；project 上下文可选 FK；类型与 project_id 非空性有检查；会话内 `(kind, ref)` 唯一。 |
| `cs_messages` | 按全局序号记录客户、坐席和系统消息，包括公开消息、内部备注、上下文和事件。 | 会话非空 FK；坐席、上下文可空 FK；sender/kind/visibility 与关联字段有检查；消息 ID 在会话+发送者范围内支持幂等唯一。 |
| `cs_message_translations` | 每条消息按目标语言保存翻译状态、译文、模型和重试信息。 | `(message_id, target_locale)` 复合主键；消息 FK，模型可空 FK；done 状态必须有译文。pending 行用于 Outbox 调度。 |
| `cs_settings` | 客服翻译、坐席语言、离线通知收件人和回复提醒配置。 | boolean 单例主键；更新管理员可空 FK。 |
| `cs_email_outbox` | 离线留言通知和坐席回复邮件投递队列。 | 会话非空 FK；同会话、类型、收件人至多一条未完成邮件的部分唯一索引；状态支持合并覆盖、重试和取消。 |

客服语言使用 PostgreSQL domain `cs_locale`，受支持语言集合由迁移定义，不是实体表。
