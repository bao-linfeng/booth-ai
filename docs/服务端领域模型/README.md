# 服务端领域模型

本目录记录服务端核心业务概念、模块边界及当前 PostgreSQL 数据关系，作为业务讨论和代码导航入口。

## 文档

- [领域模型总览](领域模型.md)：业务上下文、核心概念、关键流程与不变量。
- [领域术语表](术语表.md)：项目内统一使用的业务词汇。
- [数据库 ER 图](数据库ER图.md)：根据服务端迁移整理的当前表关系。
- [全量表设计目录](全量表设计目录.md)：逐表说明当前业务表、支撑表及历史/运维表的用途、关键字段和约束。

## 阅读口径

- 数据库结构以 `apps/server/migrations/` 全部迁移执行后的结果为准。当前文档按迁移 `080_asset_upload_requests.sql` 整理。
- ER 图只表示当前表和实际数据库外键。`--` 表示外键关系，虚线表示由业务代码、业务号或快照维护的逻辑关联，不代表数据库外键。
- JSON 快照、数组、Redis Session、BullMQ 队列、S3 对象及视图不等同于独立领域实体；需要时在对应图中注明。
- 模块职责和状态说明以当前 `apps/server/src/modules/`、`apps/server/src/workers/` 及迁移实现为依据。分模块详细设计可能描述规划或建议，不能覆盖当前实现事实。
- 修改迁移或核心关系后，应同步检查本目录文档。不要修改已执行的历史迁移来匹配图表。
