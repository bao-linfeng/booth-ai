# 方案尺寸与多语言字典

## 尺寸

- 方案固定尺寸以有方向的 `(length_mm, width_mm, height_mm)` 为整体；长表示左右，宽表示前后，旋转后视为不同尺寸。
- `booth_size` 字典条目使用 UUID 身份，`item_value` 为整数毫米组合，例如 `6000-3000-4500`；数值列用于计算，展示标签不参与比较。
- 导入、新增和编辑在保存方案的事务内调用 `ensureSelectionSizes()`，相同组合只生成一个条目。缺少任一尺寸时不生成组合。
- 面积由长×宽计算，不再维护独立面积字典。迁移 `062` 回填历史方案并备份、移除四个旧尺寸字典。
- 客户端提交 `boothSpaceId`，服务端校验并派生长宽和面积。选中尺寸时三个维度精确匹配；未选组合而提供自定义长宽时延续参考方案匹配。
- 方案高度和场馆 `maxHeightMm` 独立，选尺寸不自动填限高。客户端尺寸选项仅来自启用字典且存在当前版本审核通过的已发布方案。
- 历史尺寸条目保留；没有已发布方案使用时不在客户端出现。引用中的尺寸项不能删除，可禁用。
- Excel F 列为长、G 列为宽。`064` 仅修复已提交的指定模板导入记录中、当前尺寸仍与旧预览完全一致的非方形方案；修复前备份，更新版本并使审核/发布失效。手动调整过尺寸的记录不交换，历史项目快照保持原样，旧待提交预览过期后需重新上传。

## 语言与身份

- 方案引用字典 UUID，与界面语言无关；`item_value` 是稳定业务值，`item_label` 是默认名称。
- `labels` 保存语言代码到展示名称的映射；`aliases` 保存 `{ locale, text }` 列表，用于输入识别。
- 字典管理的“语言”入口按 `en | Modern minimalist` 格式编辑，每行一个名称或别名，别名允许同一语言多行。
- 公共目录 `GET /api/v1/client/catalog/options?locale=ja-JP` 按精确语言、基础语言、默认名称的顺序回退，也支持 `Accept-Language`。
- 默认名称、各语言名称、编码和别名均参与匹配，不以当前展示语言限制用户输入。
- 规范化包括 NFKC 全半角、去除首尾空白、合并连续空白和英文大小写。映射限定字典分类，未知或多个概念命中时要求确认。
- Excel 预览使用确定性名称/别名匹配；不自动创建元数据或由 AI 静默替代未知分类。
- 自然语言规则识别翻译与别名，模型接收完整多语言字典，仅可返回真实 ID 和原文证据。无法可靠识别的文本进入澄清。
- `063` 为既有选型词条预置英文、日文名称和常用别名。新增业务词条由后台维护翻译，缺少翻译回退默认名称。

## 验证

- `selection-dictionary-language.test.ts`：语言归一化、歧义、拉丁词边界、完整尺寸解析与限高分离。
- `selection-match.test.ts`：不同高度、旋转尺寸精确排除，限高仍独立约束。
- `selection-dictionaries-integration.test.ts`：设置 `SELECTION_TEST_DATABASE_URL`，在隔离 schema 内迁移、导入实际 48 行模板、重复导入、手动 CRUD、语言持久化和公共目录。
